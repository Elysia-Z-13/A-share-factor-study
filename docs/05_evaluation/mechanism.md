# mechanism.md —— 机制评估（E1）

> 四驱动 → DAG 三角色 → 四项证伪 → 记分卡与裁决

## 一、四种驱动选一（G1.1）

**手册规则**：每个特征必须挂到**且只挂到一个**驱动上，并写出「它为什么在这个市场成立」。

| 因子 | 驱动 | 机制叙事 |
|---|---|---|
| `gm` | **风险补偿** | 质量溢价：高毛利 = 定价能力强 = 竞争壁垒，市场对质量要求补偿 |
| `dgm_q` | **持续性** | 毛利率改善会延续（基本面动量），市场对边际改善反应不足 |
| `transfer_intensity` | **持续性** | 在建工程转固 → 产能落地 → 营收增长是持续过程 |
| `dep_rate` | **持续性** | 资产老化 → 持续资本开支压力 |
| `gm_vol` | **风险补偿** | 低波动异象：偏好彩票型的投资者低估稳定股 |

**驱动分布**：风险补偿 2 个、持续性 3 个、均值回复 0 个、可预测时钟 0 个。

**已知缺陷**：因子集合同质化（3 个持续性），缺均值回复与可预测时钟两类。

## 二、最小 DAG 与三角色判定（G1.2）

**手册的关键一句**：DAG 不是画着好看，它是**判断「该不该控制某个变量」的工具**。

### 节点与边

```
        ┌──────────┐
        │   行业    │  ← confounder（共同原因）
        └────┬─────┘
             ├──────────────┐
             ↓              ↓
      ┌────────────┐   ┌──────────────┐
      │ 毛利率 gm  │   │ 未来 60 日收益 │
      └─────┬──────┘   └───────┬──────┘
            ↓                  ↓
      ┌──────────────┐  （两者都指向）
      │ 资本开支      │
      └──────┬───────┘
             ↓
        未来收益（mediator 路径）

  另一条：毛利率 → 分析师覆盖 ← 未来收益
         （collider：两者共同导致它）
```

### 三角色判定

| 候选变量 | 箭头方向 | 角色 | 该控制？ | 理由 |
|---|---|---|---|---|
| **行业** | 行业 → 毛利率；行业 → 未来收益；毛利率 ↛ 行业 | **confounder** | ✅ **要控制** | 同时决定因子与标签，且因子不决定它 |
| **资本开支** | 毛利率 → 资本开支 → 未来收益 | **mediator** | ❌ 不要控制 | 在真实通道上，控制它切掉真实效应 |
| **分析师覆盖** | 毛利率 → 覆盖；未来收益 → 覆盖 | **collider** | ❌ **绝不能控制** | 两者共同导致它，控制它引入选择偏差 |

### 调整集

```
调整集 = {行业}

为什么不是资本开支？
  → mediator。控制它等于把「毛利率通过扩张影响收益」这条真实通道切掉
  → 除非要测「不考虑扩张的直接效应」，否则不控制

为什么不是分析师覆盖？
  → collider。毛利率与收益共同导致覆盖
  → 控制它（只分析被覆盖的股票）会凭空造出负相关
  → 手册：书里模拟造出约 −0.25 的虚假相关
```

### ⚠️ 一个我们实际没有遵守的约束

**诚实披露**：本项目的因子检验**没有做行业中性化**（F7/E1 都是在全样本上算 IC）。

按上面的 DAG，行业是 confounder，**应该控制**。

这意味着：

```
① 我们测出的 IC 里包含「行业配置」的成分
② 如果某个因子只是「选对了行业」的代理，它的 IC 会被高估
③ 制造因子（transfer_intensity / dep_rate）天然集中在一个行业内
   → 它们的 IC 可能主要是「制造业整体跑赢」而非「制造业内部选股」
```

**这是本步发现的一个真实缺口，应在 E2 补做行业内 IC。**

## 三、四项证伪（G1.3）

**手册提醒**：这四项只能「证伪」，不能「证明」。全部通过只说明「没有明显反驳证据」。

### 季度/年度面板的适配说明

| 检查 | 原始做法（日频） | 我们的做法 | 为什么改 |
|---|---|---|---|
| timing placebo | 滞后 5/21/63/126/252 天 | 滞后 **1/2/3/4 个报告期** | 因子只在报告期更新 |
| shared-driver | 换无关标签（宏观） | 同期内打乱未来收益（伪配对） | 无宏观数据；保留市场成分去掉个股归属 |
| regime 分区 | 按波动/趋势 | 按 **5 个 regime 时段** | 可用年份划分 |
| event-time | 事件窗口对齐 | 退化为确认 | label 起点由 `available_at` 定义，事件时间 = 使用时间 |

### 逐因子判读

**`dgm_q`（唯一全过）**：

```
timing: k0 +0.0279 → k1 +0.0115 → k2 +0.0115 → k3 +0.0045 → k4 +0.0009
  → 单调衰减，符合「信息逐步反映」的持续性预期 ✅
shared: -0.0012 → |IC| < 0.01 ✅（不是整体市场驱动的影子）
regime: 五段全正（+0.041/+0.033/+0.040/+0.022/+0.002）✅
  → 符号稳定，且量级单调衰减（近期趋零）
```

**`transfer_intensity`（timing 失败）**：

```
timing: k0 +0.0449 → k1 +0.0227 → k2 +0.0366 → k3 +0.0535 → k4 +0.0525
  → **非单调，且 k3/k4 比 k0 更强** ❌
  → 这正是手册的失败信号：「远处滞后仍持平甚至上升 → 它是慢变状态变量的代理」

对照 F0 的发现：transfer_intensity 是**年报数据**，4 倍时限错配
  → 它捕捉的是「制造业资本开支周期的状态」，不是「新信息」
  → 一个 3 年前的年报数据比最新的还有效，说明它不是信息驱动
```

**`gm_vol`（timing 失败）**：

```
timing: k0 −0.0310 → k1 −0.0302 → k2 −0.0296 → k3 −0.0310 → k4 −0.0258
  → **几乎完全不衰减** ❌
  → 这是典型的「慢变状态变量」：它描述的是公司长期的波动特征，不是新鲜事件
regime: 全负且一致 ✅（说明它确实是个稳定的状态特征）
→ 结论：gm_vol 是个有效的「状态变量」（state），但不是「信号」（signal）
→ 按 F0 的角色分离原则，它应该被重新归类为 state，用于 gating 而非排序
```

**`gm`（regime 失败）**：

```
timing: k0 +0.0251 → k4 +0.0100 ✅ 单调衰减
shared: +0.0060 ✅
regime: 2010-2013 +0.117, 2014-2015 +0.008, 2016-2018 +0.007,
        2019-2021 +0.030, 2022-2024 **−0.060** ❌
  → 最近一个 regime 符号翻转且量级显著（−0.060）
  → 手册的失败信号：「某一区符号翻转且显著」
```

**`dep_rate`（timing 警示 + regime 失败）**：

```
timing: k0 +0.0346 → k1 +0.0121 → k2 +0.0059 → k3 +0.0129 → k4 −0.0025
  → k3 反弹（+0.0129 > k2 +0.0059）→ 非严格单调 ⚠️
regime: 2016-2018 −0.015, 2022-2024 −0.059 → 两段为负 ❌
```

## 四、记分卡与裁决（G1.4）

| 因子 | 驱动可命名 | DAG 可画 | timing | shared | regime | event | 通过数 | 失败数 | **裁决** |
|---|---|---|---|---|---|---|---|---|---|
| `gm` | ✅ | ✅ | ✅ | ✅ | ❌ | ✅ | 3/4 | 1 | **STOP** |
| `dgm_q` | ✅ | ✅ | ✅ | ✅ | ✅ | ✅ | 4/4 | 0 | **PROCEED** |
| `transfer_intensity` | ✅ | ✅ | ❌ | ✅ | ❌ | ✅ | 2/4 | 2 | **STOP** |
| `dep_rate` | ✅ | ✅ | ⚠️ | ✅ | ❌ | ✅ | 2/4 | 1 | **STOP** |
| `gm_vol` | ✅ | ✅ | ❌ | ✅ | ✅ | ✅ | 3/4 | 1 | **STOP** |

### 裁决说明

```
PROCEED：驱动可命名 + 四项里至少三项通过 + 没有失败项
REVISE ：有 1~2 项警示，或 DAG 角色判不清 → 改定义重跑
STOP   ：驱动说不出，或出现任一失败项
```

**手册原话**：REVISE 是常态，不是失败。真正该停的是「说不出机制又过不了证伪」的那一类。

**本次结果：1 个 PROCEED、4 个 STOP。**

## 五、本步最重要的发现：一条完整的因果链

```
F0 的时限检查：transfer_intensity / dep_rate 是年报数据，4 倍时限错配
        ↓
E1 的 timing placebo：远处滞后 IC 不衰减甚至更强
        ↓
E1 裁决：STOP（它是慢变状态代理，不是信息驱动）
```

**这条链说明**：时限对齐不是形式主义——错配的因子会在 timing placebo 上暴露。

而唯一时限对齐正确的 `dgm_q`（季频，等长匹配），也是唯一 4/4 全过的因子。

**这不是巧合，是机制一致性的体现。**

## 六、对后续步骤的约束

| 步骤 | 约束 |
|---|---|
| **E2 信号评估** | ①必须补**行业内 IC**（DAG 说行业是 confounder，我们之前没控制）②`gm_vol` 应重新归类为 state，不进排序 ③`transfer_intensity`/`dep_rate` 的 IC 需注明「可能是制造业行业效应」 |
| E3 模型成立 | 只剩 `dgm_q` 一个因子通过，模型复杂度应进一步降低 |
| E4 策略评估 | 需对比「全样本选股」与「行业内选股」的差异 |

## 七、已知局限

1. **未做行业中性化**（最大的缺口）：DAG 判定行业是 confounder，应控制，但我们没有
2. `shared-driver` 的伪标签用的是「同期打乱的收益」，它保留了市场成分，但检验力弱于真正的「无关结果」
3. `event-time` 检查退化为确认（我们的标签起点已由 available_at 定义），没有独立的检验力
4. regime 划分用的是固定年份区间，而非数据驱动的状态识别（后者会引入前视）
5. 五项证伪都是**证伪**性质，全过不代表因果成立
