# cost.md —— 成本评估（E5）

> 三层成本 ｜ 按参与率选档 ｜ 参数取上半区 ｜ 滑点单独翻倍 ｜ break-even ≥ 2× 真实成本

## 一、成本三层拆解

### 显式成本（A 股，2024 年费率）

| 项 | 费率 | 方向 | 单边成本 |
|---|---|---|---|
| 佣金 | 万分之 2.5（2.5bp），最低 5 元 | 买卖双向 | 2.5bp |
| **印花税** | **千分之 1（10bp）** | **仅卖出** | 卖出 +10bp |
| 过户费 | 万分之 0.1（0.1bp） | 买卖双向 | 0.1bp |
| **合计** | — | — | **买入 2.6bp / 卖出 12.6bp** |

**往返显式成本 = 15.2bp**

### ⚠️ E4 用 10bp 是偏低的

```
E4 用统一 10bp
实际往返 15.2bp（印花税只在卖出，所以买卖不对称）
均摊单边 7.6bp，比 10bp 高 -2.4bp
→ 单看显式成本，E4 低估了约 24%
```

### 隐式成本（价差 + 滑点）

按手册的三档划分，取值一律取**区间上界**（保守）：

| 市值档 | 价差区间 | 取上界 | 固定滑点区间 | 取上界 |
|---|---|---|---|---|
| 大盘（前 300） | 5–10bp | 10bp | 5bp | 5bp |
| 中盘（301–1000） | 10–20bp | 20bp | 15–25bp | 15bp |
| 小盘（> 1000） | 20–50bp | **50bp** | 15–25bp | **25bp** |

## 二、参与率与三档模型（G4.6）

**假设**：AUM = 1 亿，持仓 723 只等权，换手 52.6%/期。

**参与率计算**：

```
下单金额 = AUM × 每只权重 × 换手率
         = 1亿 × (1/723) × 0.526 = 72,751 元

参与率 = 下单金额 ÷ 该股日均成交额（ADDV）
```

| 档位 | 假设 ADDV | 参与率 | 落档 | 单边成本 |
|---|---|---|---|---|
| 大盘 | 5 亿 | **0.01%** | 价差模型（<0.5%） | **12.6bp** |
| 中盘 | 2 亿 | **0.04%** | 价差模型（<0.5%） | **17.6bp** |
| 小盘 | 3000 万 | **0.24%** | 价差模型（<0.5%） | **32.6bp** |

**组合加权单边成本 = 20.9bp**（三档等权）

**⚠️ 一个必须说清的观察**：

```
三档的参与率都远低于 0.5%
→ 所有档位都落在「价差模型」
→ 成本由价差主导，不是冲击主导
→ 这意味着：若 AUM 大幅增加，成本结构会切换
   例：AUM 从 1 亿涨到 10 亿 → 参与率 ×10 → 小盘档 2.4% → 落到平方根冲击
```

## 四、break-even 与判定（G4.10）

### 成本敏感性网格

| 单边成本 | 2 因子净超额 | 3 因子净超额 |
|---|---|---|
| 0bp | +2.20% | +3.11% |
| 5bp | +1.98% | +2.89% |
| 10bp | +1.75% | +2.68% |
| 15bp | +1.53% | +2.47% |
| 20bp | +1.31% | +2.26% |
| 30bp | +0.86% | +1.84% |
| 40bp | +0.42% | +1.41% |
| 60bp | -0.46% | +0.57% |
| 80bp | -1.34% | -0.26% |

### break-even

| 组 | break-even | 真实成本 | **倍数** | 判定（手册 3× / 门禁 2×） |
|---|---|---|---|---|
| 2 因子 | 49.5bp | 20.9bp | **2.36×** | ✅ 勉强（1–3×，过 2× 门禁） |
| 3 因子 | 73.8bp | 20.9bp | **3.52×** | ✅ 稳健（≥3×） |

### ⚠️ 一个与前几步方向相反的结果

```
E4：2 因子 Sharpe 1.01 > 3 因子 0.65  → 2 因子更好
E5：2 因子 break-even 2.36× < 3 因子 3.52× → 3 因子更好

为什么？
  break-even = 毛超额 ÷ (年换手 × 2)
  2 因子：毛超额 2.20%，年换手 2.10 倍 → break-even 49.5bp
  3 因子：毛超额 3.10%，年换手 1.98 倍 → break-even 73.8bp
  → 3 因子毛超额更高、换手更低 → 成本容忍度更高

  Sharpe 低是因为波动大，不是因为收益低
  break-even 高是因为收益高，不是因为波动小

→ 这是两个不同的维度：
  「单位风险收益」看 2 因子
  「成本容忍度」看 3 因子
→ 最终选哪个，要在 E7/E8 结合风险偏好决定
```

## 五、滑点单独翻倍压测（G4.7）

**手册要求**：把滑点拆成「固定 + 与参与率相关」两部分；压力测试里单独把滑点翻倍。

| 组 | 基准单边成本 | 滑点翻倍后 | 净超额（翻倍后） |
|---|---|---|---|
| 2 因子 | 20.9bp | **34.3bp** | **+0.67%** |
| 3 因子 | 20.9bp | 34.3bp | +1.66% |

**判读**：滑点翻倍后（单边约 34bp），两组的净超额仍为正。
这说明策略的成本容忍度不依赖「滑点恰好很小」这个假设。

### 未能做的滑点建模

| 手册要求 | 状态 | 原因 |
|---|---|---|
| 滑点与波动成正比（波动期 2–3 倍） | ❌ 未做 | 需要逐期波动率与逐笔成本数据 |
| 滑点与时段有关（开盘收盘） | ❌ 未做 | 需要日内数据（我们只有日频） |
| 危机期成本整体上移数倍 | ❌ 未做 | 同上 |

**这三项是 E5 的已知缺口。** 我们只做了「翻倍」这一种整体放大，未做条件放大。

## 六、现金可用时点（G4.14）

| 规则 | A 股约定 |
|---|---|
| 市场 | A 股 |
| **卖出资金何时可再投入** | **T 日（T+0 资金）** |
| **买入证券何时可卖** | **T+1（T+1 证券）** |
| 订单顺序 | **先卖后买** |
| 同一股票日内回转 | **不允许**（变相 T+0，券商风控会拦） |

**⚠️ 一个容易混淆的点**：

```
「资金 T+0 可用」是指可用于买入其他股票
不代表「卖掉 A 后能立刻买回 A」（那是变相 T+0，不允许）
```

**对我们回测的影响（如实声明）**：

```
E4 的向量化引擎把「权重从 w_old 换到 w_new」视为一次性交易
→ 隐含假设「资金无限周转」
→ 严格说这不符合「先卖后买」的现金约束

影响量级：季度调仓、换手 52.6%
→ 卖出与买入金额都约占总资产的 52%
→ 若必须先卖后买，需要 T 日内完成两笔
→ A 股 T+0 资金规则下是可实现的
→ 所以这个隐含假设在实践中无害，但必须写出来
```

## 七、结论

| 项 | 2 因子 | 3 因子 |
|---|---|---|
| 毛年化 | +6.56% | +7.46% |
| 净年化（真实成本） | +5.63% | +6.57% |
| 基准 | +4.36% | +4.36% |
| **净超额** | **+1.26%** | **+2.22%** |
| **gross 为正** | ✅ | ✅ |
| **net 为正** | ✅ | ✅ |
| **break-even 倍数** | **2.36×** | **3.52×** |
| 滑点翻倍后净超额 | +0.67% | +1.66% |

**门禁 G4.10 判定**：2 因子 2.36×、3 因子 3.52×，**均过 ≥2× 门槛**。
按手册的 3× 判读，3 因子「稳健」，2 因子「勉强」。

### 本步最重要的三条

```
① E4 的 10bp 低估了 2.1 倍（真实 20.9bp）
   → 净超额从 +1.75% 修正为 +1.26%

② break-even 只有 2.36×（2 因子）——刚过门槛，余量不足
   → 若真实成本翻倍到 42bp，净超额归零
   → 这不是一个「成本很安全」的策略

③ 3 因子的成本容忍度反而更好（3.52× vs 2.36×）
   → 与 E4 的 Sharpe 结论方向相反
   → 两个维度要分开看，最终在 E8 权衡
```

## 八、已知局限

1. **ADDV 是假设值**（5亿/2亿/3000万），不是实测。我们有成交额数据，但未按股票逐只匹配市值档
2. **市值档划分是粗的**（大/中/小各 1/3），实际应按流通市值分位
3. **滑点的条件建模未做**（波动相关、时段相关、危机放大）
4. **佣金最低 5 元未建模**（对大单无影响，对小单有影响）
5. **未扣机会成本与拥挤度**（手册第三层成本）
6. **未做 TCA 闭环**（需要实盘成交回执，属 P 段）
