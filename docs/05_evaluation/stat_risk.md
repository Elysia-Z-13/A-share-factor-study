# stat_risk.md —— 统计推断与风险（E7）

> Sharpe 是估计量 ｜ 搜索抬高最大值 ｜ 尾部用 CVaR ｜ 回撤要报恢复时间 ｜ 压力八项 ｜ 泄漏五查

## 一、Sharpe 是估计量（G5.4 的前置）

**公式**：`SE(SR) ≈ √((1 + ½·SR²) ÷ T)`，T 用**年数**不是期数。

| 项 | 2 因子 | 3 因子 |
|---|---|---|
| 超额 Sharpe（年化） | **+0.728** | +0.536 |
| T（年） | 17 | 17 |
| SE(SR) | 0.273 | 0.259 |
| **95% CI** | **[+0.193, +1.262]** | [+0.028, +1.045] |
| 达到 t=2 所需年数 | 9.6 年 | 15.9 年 |
| 实际年数 | 17 年 | 17 年 |
| 是否足够 | ✅ | ✅ |

**⚠️ 3 因子的 95% CI 下限只有 +0.028**——几乎触及零。这意味着「3 因子有正超额」这个结论在统计上非常脆弱。

**手册的警告被验证**：
```
要让 SR=0.5 达到统计显著，需要约 24.7 年
我们只有 17 年
→ 温和的 Sharpe 在 17 年样本里，连「显著」都很难达到
```

## 二、搜索预算自检

**公式**：`最少样本长度 ≈ 2·lnN ÷ SR²`

| 项 | 2 因子 | 3 因子 |
|---|---|---|
| N（trial 账本） | 15 | 15 |
| 所需年数 | 10.2 | 18.8 |
| 实际年数 | 17 | 17 |
| 判定 | ✅ 足够 | ❌ **不足** |

**3 因子的样本长度不够支撑 15 次试验**——这是它 DSR 更低的直接原因。

## 三、DSR：本步的硬性失败（G5.4）

**必须区分两个口径**：

| 口径 | 含义 | 适用 |
|---|---|---|
| **绝对收益** | 净收益本身的 Sharpe | 涵盖市场 beta，评估「这个产品好不好」 |
| **超额收益** | 净收益 − 等权 universe | **纯 alpha**，评估「这个策略有没有选股能力」 |

**我们对 alpha 的主张应该用超额口径**，但同时报绝对口径供参考。

| 组 | 口径 | Sharpe | E[max\|N=15] | z | **DSR** | 判定 |
|---|---|---|---|---|---|---|
| 2 因子 | 绝对 | +0.385 | 0.445 | -0.239 | **0.4054** | ❌ |
| 2 因子 | **超额** | +0.728 | 0.483 | +0.898 | **0.8153** | ❌ |
| 3 因子 | 绝对 | +0.437 | 0.450 | -0.049 | **0.4806** | ❌ |
| 3 因子 | **超额** | +0.536 | 0.459 | +0.297 | **0.6169** | ❌ |

### 手册的判读标准

| DSR | 判读 |
|---|---|
| **> 0.95** | 通过 |
| **0.5–0.95** | **证据不足** |
| < 0.5 | 基本没有证据 |

### 落点

```
2 因子：DSR 超额 0.8153 → 落在「证据不足」区间（0.5–0.95）
3 因子：DSR 超额 0.6169 → 同样「证据不足」
（绝对口径更低：0.4054 / 0.4806）

→ **门禁 G5.4 要求 DSR > 0.95，我们不通过。**
```

### 为什么不过：三个乘数的算术

```
DSR 门槛 = E[max|N=15] = SE × √(2 ln 15)
         = 0.273 × 1.893 = 0.483

我们的 SR = 0.728
差距 = +0.245
达到 DSR=0.95 需要 SR > E[max] + 1.645×SE = 0.932

→ 要么 SR 从 0.73 提到 0.93（+28%）
→ 要么 T 从 17 年提到约 28 年（SE 降到 0.213）
→ 两者都不是「调参」能解决的
```

### 这不是 bug，是样本量的结构性限制

```
我们只有 2010-2026 共 17 年数据
→ 不能凭空延长
→ 也不能减少 N（15 次试验是真实发生的）
→ 唯一诚实的结论：证据不足
```

## 四、PBO（G5.5，warn 项）

**PBO = 回测过拟合概率**（Probability of Backtest Overfitting）：
衡量「样本内选出最优的参数，在样本外是否系统性变差」。

**我们的情况特殊**：

```
我们的模型是零参数等权合成
→ 没有「参数网格」可选
→ 经典 PBO（基于参数选择）在结构上不适用
```

**但仍有搜索风险，只不过搜索对象是「结构」而非「参数」**：

| 搜索维度 | 试过几个 | 风险 |
|---|---|---|
| 因子子集 | 4 个（全3/删gm_vol/删gm/只剩dgm_q） | 中 |
| 合成方式 | 2 个（等权/IC加权） | 低（实测差异 0.0001） |
| 分组（全市场/制造业） | 2 个 | 中 |
| 标的分组（是否剔小盘） | 未做 | — |

**结构搜索的有效 N ≈ 4×2×2 = 16，与 trial 账本的 15 一致。**
所以 DSR 的 N=15 已经反映了这个搜索强度，不需要额外的 PBO 校正。

**PBO 结论**：经典 PBO 不适用（零参数）；结构搜索风险已由 DSR 的 N 捕获。

## 五、尾部：CVaR（G5.6）

**手册为什么要求 CVaR 而不是 VaR**：

> VaR 只给阈值，不说什么在阈值之外；**破线时亏 3% 与亏 20% 在 VaR 里一样**。

| 组 | VaR(95%) | **CVaR(95%)** | CVaR/VaR |
|---|---|---|---|
| 2 因子 | 0.92% | **1.28%** | 1.39× |
| 3 因子 | 2.54% | **2.93%** | 1.15× |

**CVaR 是真实的尾部损失**：2 因子的最差 5% 期间，平均每期亏 1.28%（VaR 只告诉你门槛是 0.92%）。

**⚠️ 3 因子的尾部风险是 2 因子的 2.3 倍**（2.93% vs 1.28%）——这是它 Sharpe 更低的直接原因。

## 六、回撤与恢复时间（G5.6）

**手册**：回撤是路径问题，不只看终点；要报 MDD、**恢复时间**、条件回撤。

| 组 | MDD | 谷底期 | **恢复时间** | 水下期数 | 条件回撤（>10% 部分均值） |
|---|---|---|---|---|---|
| 2 因子 | -53.7% | 第 42 期 | **8 期（约 2.0 年）** | 0 | -33.5% |
| 3 因子 | -52.0% | 第 42 期 | **5 期（约 1.2 年）** | 0 | -32.4% |

**判读**：
```
MDD −53.7%（2 因子），谷底在第 42 期（约 2020 年），之后 8 期（2 年）恢复
→ 这个回撤主要是市场 beta（2020 疫情 + 2022 熊市）
→ 对一个 long-only 股票策略，−50% 级别的回撤是正常的
→ 但对投资者体验是致命的：需要 2 年才能回本
```

**⚠️ 一个必须指出的问题**：MDD −53.7% 超过了 E6 里 K4 kill 判据的阈值（−52.4%），
意味着**如果按 K4 部署，回测期本身就已经触发过一次 kill**。

## 十、holdout 解锁（只开一次）

**D5 的设计**：留出最后约 20% 的数据（2023-2024），只在 E7 打开一次。

**解锁前的预期（必须先写下来）**：

```
基于 M-V 的分年 IC（2022 −0.041、2023 −0.034、2024 +0.018）
与 E4 的分年净超额（2022 −0.1%、2023 +0.1%、2024 −0.0%）

预期：holdout 段的净超额接近 0，可能略负
预期：IC 方向为正但量级显著低于全期

如果 holdout 净超额 > 0 且 IC > 0.02 → 意外的好结果，需检查是否泄漏
如果 holdout 净超额 < −1% → 确认失效
```

**⚠️ 状态：holdout 尚未解锁。**
原因：E7 已在 DSR 上不过（0.8153 < 0.95），按门禁未通过。
在统计证据不足的情况下打开 holdout 会浪费它唯一的解锁机会——
正确顺序是先解决 DSR 问题，再开 holdout。

**这意味着 holdout 的解锁被推迟到门禁通过之后。**

### 本步的判决

```
**E7 不通过。**

唯一失败的检查是 G5.4（DSR > 0.95）。

DSR = 0.8153 落在手册的「证据不足」区间（0.5–0.95）
→ 不是「策略无效」，而是「样本量不足以支持统计结论」
```

### 为什么这个失败是真实且不可回避的

```
DSR 门槛 = SE × √(2 ln N) = 0.273 × 1.893 = 0.483
我们的 SR = 0.728
要达到 DSR 0.95，需要 SR > 0.483 + 1.645 × 0.273 = 0.932

三条出路：
① 把 SR 从 0.73 提到 0.93（+28%）—— 需要新的 alpha 源，不是调参
② 把 T 从 17 年提到 28 年 —— 不可能，我们只有 2010-2026
③ 把 N 从 15 降到 3 —— 不诚实，15 次试验是真实发生的

→ 没有第四条路
→ 所以正确的做法是：承认证据不足，不给「策略成立」的结论
```

### 这与前几步的结论怎么统一

| 步骤 | 结论 | 是否矛盾 |
|---|---|---|
| E3 | 模型成立（对有 E1-valid 的基线增量显著） | 不矛盾：E3 检验「相对基线」，E7 检验「相对搜索偏差」 |
| E4 | 策略成立（弱），净超额 +1.75% | 不矛盾：E4 是点估计，E7 是置信度 |
| E5 | break-even 2.36× 过关 | 不矛盾：成本容忍度 ≠ 统计显著性 |
| E6 | 容量 0.43 亿，1 亿不可行 | 不矛盾：这是规模约束，独立于显著性 |
| **E7** | **DSR 0.8153，证据不足** | **这是对前面所有结论的「置信度折扣」** |

**正确的整体表述**：
```
有一个点估计为正（净超额 +1.26%/年）、成本能承受（break-even 2.36×）、
但统计证据不足（DSR 0.8153）、规模受限（容量 0.43 亿）的因子。

它「可能」是真的，但用 17 年、15 次试验的数据，我们
无法把「可能」升级成「确定」。
```
