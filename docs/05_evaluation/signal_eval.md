# signal_eval.md —— 信号评估（E2）

> H=60 交易日 ｜ 单边成本 10bp ｜ 往返 0.20%

## 一、IC 口径（G1.6）

**手册的四条硬规则**：

| 项 | 本次做法 |
|---|---|
| 计算单位 | **每个报告期算一次** rank IC，再对期取平均 |
| 显著性 | t 值用 **HAC（Newey-West，滞后 L = H = 60）** |
| 样本数 n | **有效报告期数**（70~74 期），不是股票-日 |
| 报告内容 | 均值、ICIR、HAC t、正的占比、分折 |

**为什么 n 必须用期数**：
```
若用股票-日：n = 184,456 → t = mean/std × √184456 ≈ 430
→ 荒谬。因为同一期的 4,000 只股票不是独立观测
```

**为什么必须 HAC**：
```
H=60，相邻期的标签窗口重叠 → IC 序列自相关
→ 朴素 SE = std/√n 低估 → t 虚高
→ HAC 用 Bartlett 核修正：SE² = γ0 + 2Σ(1−j/(L+1))γ_j
```

### 关键判读

**HAC 使 t 值普遍下降 1/1.3 ~ 1/1.9**，直接改变了三个结论：

```
① gm：t_naive 1.91（接近显著）→ t_hac 1.03（不显著）
   → 这个因子在正确的统计口径下无效

② 全市场组合成：t_naive 5.03 → t_hac 3.09
   → 刚过 t>3 的新因子门槛，余量极小

③ dgm_q：t_naive 5.92 → t_hac 4.19
   → 仍稳稳过门槛（唯一一个余量充足的）
```

**一个异常**：`dep_rate` 的 SE 膨胀仅 0.73×（HAC 的 SE 比朴素还小）。
这意味着它的 IC 序列有**负自相关**。在只有 15 期的情况下，这更可能是噪声而非结构。

## 六、行业内 IC（E1 的 DAG 要求）

### ⚠️ 先说数据限制

**E1 的 DAG 判定「行业 = confounder，应控制」，但我们无法严格做到**：

```
data/sector_*.csv 的行业分类只有 3.4% 非空（196/5776 只）
且每个文件只有一个日期（是快照，不是历史快照）
→ 无法重建「当时所属行业」
→ 不能做真正的行业内 IC
```

**替代方案**：用「是否制造业」作为粗糙的行业代理（2 组）。
制造业 = transfer_intensity 非空（即披露了固定资产附注）。

| 因子 | 非制造业 IC | 制造业 IC | 差异 |
|---|---|---|---|
| dgm_q（E1 唯一 PROCEED） | +0.0259 | +0.0347 | +0.0088 |
| 全市场组合成（3 因子） | +0.0496 | +0.0570 | +0.0074 |
| gm（E1 STOP，作对照） | +0.0256 | +0.0235 | -0.0021 |
| gm_vol（E1 STOP，应归 state） | -0.0295 | -0.0364 | -0.0068 |
| transfer_intensity（E1 STOP） | — | +0.0449 | 只在一个组有样本 |
| dep_rate（E1 STOP） | — | +0.0346 | 只在一个组有样本 |

**判读**：
```
dgm_q：非制造业 +0.0259 / 制造业 +0.0347 → 两组都正，制造业略强
全市场组合：+0.0496 / +0.0570 → 两组都正
→ 因子不是单纯的「行业配置」效应（否则非制造业组会接近 0）

```

**这个替代方案的局限**：只有 2 组，无法像申万 31 个行业那样真正中性化。
**结论**：行业内 IC 只做了粗略验证，是 E2 的一个已知缺口。

## 八、已知局限

1. **行业内 IC 只做了 2 组粗代理**：真正的申万 31 行业中性化无法做（行业字段 3.4% 非空）
2. **多头超额如此之低是一个需要复核的发现**：可能是因为我们的十分位是按「当期截面」分的，而 long-only 组合实际只买 top-30%，不是 top-10%
3. **换手代理用 top-30% 定义**，与实际组合权重（等权 vs IC 加权）不完全一致
4. **`dep_rate` 的 HAC 膨胀 < 1**（0.73）在 15 期下不可信，可能低估其真实 t
5. `dgm_q` 与「全市场组合」的 IC 口径不同（前者单因子，后者三因子等权），不能直接比大小
6. 未做 BH/Holm 逐步校正（只报了 Bonferroni 单步门槛）
