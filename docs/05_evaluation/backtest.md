## 一·五、十项成交语义（G4.12：逐条写死）

**手册要求**：向量化引擎的每一项默认值都要写进配置，否则你测的是引擎作者的偏好。

| # | 语义 | 本项目的取值 | 为什么这样定 |
|---|---|---|---|
| 1 | **成交时点** | **T+1 开盘（09:30 集合竞价成交）** | D4 标签口径；T 日 15:00 后无法交易 |
| 2 | **成交价** | **`open_adj[t+1]`（复权开盘价）** | 与标签同一条价格序列，避免"标签复权、回测不复权"的口径漂移 |
| 3 | **订单顺序** | **先卖后买**（向量化引擎隐式满足） | 等权组合卖出与买入金额相等，现金不占用；若先买后卖会需要过桥资金 |
| 4 | **权重换算** | **等权 top-30%**，每只 1/k（k ≈ 723） | 评分只用于排序（M-S 结论），权重不依赖分数大小 |
| 5 | **现金记账** | **不持现金**（权重和 = 1） | 无杠杆、无闲置资金；成本从权重里扣，不产生负数现金 |
| 6 | **股数** | **连续权重，不做整手取整**（见下节讨论） | AUM 假设足够大，取整误差 < 0.5% |
| 7 | **卖空** | **不允许**（A 股默认） | 融券成本高、券源有限 |
| 8 | **止损** | **无**（持有到 label 到期） | 止损需要事件驱动引擎（下一步依赖当前净值） |
| 9 | **缺失 bar** | **停牌不成交、不持有、净值不因它变化** | 停牌日无行情 → 无 label → 该股不进入当期候选 |
| 10 | **成本模型** | **`换手 × 2 × 10bp`，在成交时扣，参与复利** | 佣金 2.5bp + 印花税 5bp（卖出）+ 过户费 0.1bp + 滑点 2.4bp ≈ 10bp |

**逐条的可验证性**：

```
① 成交时点：代码中收益从 open_adj[t+1] 起算，T 日价格不参与 → 可验证
② 成交价：`label` 的构造在 D4 已定义，回测直接复用 → 可验证
③ 订单顺序：等权组合买卖金额相等，顺序不影响结果 → 结构性满足
④ 权重换算：`w = 1/k`，代码可见 → 可验证
⑤ 现金：权重和 = 1，无现金项 → 结构性满足
⑥ 股数：连续权重，未取整 → 见下节误差分析
⑦ 卖空：`nlargest(k)` 只做多 → 可验证
⑧ 止损：无止损代码 → 结构性满足
⑨ 缺失 bar：只用有 label 的行 → 可验证
⑩ 成本：`net = (1+gross)×(1−换手×2×cost)−1` → 可验证
```

## 一·六、整手规则与零股处理（G4.13）

### 规则定义

**A 股规则**：买入必须是 **100 股的整数倍**；卖出时可以拆出零股（不足 100 股的部分一次性卖出）。

### 本项目的处置：**不建模整手，但给出误差量级**

**理由**（定量）：

```
组合持仓 723 只，等权 → 每只权重 = 1/723 = 0.138%

不同 AUM 下的单只持仓金额与整手误差：
  AUM = 100 万   → 每只 1,383 元   → 10 元股约 138 股 → 取整到 100 股 → 误差 −28%
  AUM = 1,000 万 → 每只 13,831 元  → 10 元股约 1,383 股 → 取整到 1,300 股 → 误差 −6%
  AUM = 1 亿     → 每只 138,310 元 → 10 元股约 13,831 股 → 取整误差 −0.4%
  AUM = 10 亿    → 每只 1,383,100 元 → 取整误差 −0.04%
```

**结论**：

```
假设 AUM ≥ 1 亿（本项目的研究设定），整手误差 < 0.5%，在成本模型的噪声范围内
→ 不建模整手，但在报告中声明这个假设
```

**若 AUM < 1,000 万**：

```
整手误差可达 6%~28%，且会让"等权"变成"不等权"
→ 必须建模整手，并考虑用「最小市值股 + 剩余资金」的补足逻辑
→ 本项目的结论（净超额 +1.75%）在小资金下会显著高估
```

### 零股处理

```
卖出时：零股可一次性卖出（A 股规则允许）
清仓时：不足 100 股的零头全部卖出
→ 本项目不建模（因为不建模整手，所以也不产生零股）
```

### 与 E6 的衔接

```
E6（换手容量）会用真实 ADDV 计算容量上限
→ 届时会给出「在多大 AUM 下整手误差 < 0.5%」的精确数字
→ 本节的 1 亿是粗估，以 E6 为准
```

## 一·七、基准的定义（G4.3）

**本项目基准 = `等权universe`（自算）**

**具体实现**：

```
对每一个调仓期 t：
  universe_t = 当期 tradable=True 且非涨停、且有 label 的股票
  bench_ret_t = universe_t 内所有股票 label 的等权平均
```

**为什么不用指数**（手册原话）：

> **不要用指数替代自己的宇宙**——那会把"宇宙差异"混进"策略超额"。

**与指数基准的差异（定性）**：

```
我们的 universe ≈ 4,500 只（剔 ST/次新/低流动性）
沪深 300 = 市值最大的 300 只
→ 我们的 universe 偏中小市值
→ 若用沪深 300 作基准，超额里会混进"小市值溢价"
→ 那不是选股能力
```

**一个已知的偏差（如实标注）**：

```
bench_ret_t 是「有 label 的股票」的等权平均，不是「全部 tradable 股票」的等权持有净值
→ 有 label 要求 T+1 与 T+H+1 都有行情
→ 长期停牌股会被排除在基准之外
→ 轻微高估基准（因为停牌股复牌后常见补跌）
→ 方向是「让策略的超额显得更保守」，不算粉饰
```

## 三、判定：多头端 vs 等权 universe

**手册的判定标准**：

> `多头端年化净超额 > 0` **且** `跑赢等权基准`，才算策略成立；多空价差只作为**信号质量的旁证**。

| 组 | 年化净收益 | 基准 | 净超额 | 跑赢基准？ | 判定 |
|---|---|---|---|---|---|
| **2 因子** | +6.12% | +4.36% | **+1.75%** | ✅ | **成立（弱）** |
| 3 因子 | +7.04% | +4.36% | +2.68% | ✅ | 成立但更不稳 |

**一个反直觉的结果**：

```
3 因子的净超额更高（+2.68% vs +1.75%）
但 Sharpe 更低（+0.65 vs +1.01）
→ 3 因子超额大但波动更大 → 单位风险收益更差
→ 这印证了 E3 的发现：删掉 gm 后 t_hac 从 3.06 涨到 7.89
→ **2 因子是更好的选择**（E3 的建议被 E4 证实）
```

| 项 | 结论 |

### 与前面步骤的呼应

```

E4：实盘化后年化净超额 +1.75% = 0.44%/期
```

## 七、已知局限

1. **benchmark 用的是「同一批可交易股票的等权 label 平均」**，不是真正的等权持有净值——因为 label 是 H=60 的未来收益，用它当基准会略高估基准（样本是「有 label 的」而非「全部 tradable」）
2. **未做 regime 四态切片**（需滚动波动与趋势，本步时间有限）
3. **未做四项压力测试**（见上）
4. **MDD −52% 是长仓 beta，不是策略缺陷**——但 long-only 下无法规避
5. **未扣冲击成本**，只扣了 10bp 线性成本
6. 分年度的「净超额」是各年期内超额的平均，不是年度复利超额
