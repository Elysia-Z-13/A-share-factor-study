## 四、三条高危字段说明

**可观测性**：5 个因子的输入全部来自财报（FS_Comins / FN_Fn020），
因此可用时点必须是 `公告日 ann_date 盘后`，不是报告期 end_date。
这条写错就是前视——D2 实验实测会使 IC 虚高 1.78 倍。

**参考系**：全部用横截面（因为策略是横截面选股）。
手册明确：换参考系 = 改含义 = 新假设 = 重跑全套。

**表示**：全部用 rank（降噪，单调变换秩不变）。
若改为「去残差」（正交化掉 rev20+mom250），属于改含义，需重新记账。

## 五、已知局限

1. `transfer_intensity` 与 `dep_rate` 覆盖率仅约 19.8%（只有制造业披露附注）
2. `gm_vol` 回看窗 240 日 = 4×H，属倍长，IC 预期低于等长因子
3. `dep_rate` 驱动强度标为「弱」，即使 IC 显著也需更严的样本外验证
4. 全部 5 个因子都是横截面参考系，未做时序参考系版本
