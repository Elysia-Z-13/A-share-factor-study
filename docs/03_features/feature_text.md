## 二、第 7 问：知识截止（G-F5.2 硬门）

**我们的答案**：本项目**不使用任何预训练语言模型**，
因此不存在「模型知道未来」的污染风险。硬门通过。

**若未来要做，安全条件**：

```
模型知识截止时间 < 回测起点（2010-01-01）
```

**现实约束**：

| 方案 | 是否满足 | 说明 |
|---|---|---|
| 纯词典（人工构造，无训练） | ✅ | **唯一绝对安全** |
| BERT-base（2018 发布，语料截止 2018） | ❌ | 晚于 2010 起点 |
| GPT-4（截止 2023-10） | ❌ | 严重污染 |

**这是一个真问题**：只要回测起点是 2010，几乎所有现代 NLP 模型都不干净。
想做文本因子只有三条路：① 用词典（安全但效果差）
② 把回测起点推到 2019+（样本太少）③ 承认污染并披露。

**所以「本项目不做文本」是理性决定，不是偷懒。**

## 四、信号族与手册实证

| 信号 | 手册实证 | 我们的判断 |
|---|---|---|
| 情绪（正负向） | 都不显著 | ⚠️ 手册实证不支持 |
| 不确定性（模糊/风险词） | 可用词表法 | ⚠️ 可试 |
| 叙事变化（同公司前后文风变化） | 5 日 IC −0.151 显著；20 日 +0.059 不显著 | ✅ 最值得做 |
| 事件抽取（并购/监管/指引） | 需 schema | ⚠️ 复杂 |
| 相似度（与同业文本） | 需同业分组 | ⚠️ 中等 |

**手册的关键结论**：「变了什么」比「有多正面」更有信息。

**两条推论**：
① 市场对「公司说了什么」反应充分（情绪无效），
   但对「公司换了说法」反应不足（叙事变化有效）→ 行为偏差
② 5 日显著、20 日不显著 → 信息在 5 日内消化
   → 文本信号的尺度是「天」不是「季度」→ 与 H=60 不匹配

**这印证了 F0 的时限对齐**：如果要做叙事变化因子，标签应改成 H=5，
那是另一个实验（改含义），必须重新记账。

## 五、图特征与三时间戳

| 时间戳 | 含义 | 例子 |
|---|---|---|
| 事件时间 | 事情发生 | 2024-03-15 并购签约 |
| 知识时间 | 你什么时候知道 | 2024-03-16 公告 |
| 快照时间 | 数据抓取 | 2026-11-20 下载 |

**关系**：`事件时间 ≤ 知识时间 ≤ 快照时间`，缺一个就前视。

**本项目**：不使用图特征（无供应链、无机构持仓数据），
但三时间戳框架与 D0 的 `available_at` 完全一致，可作方法论参考。

## 六、为什么本项目不做文本

1. **数据**：CSMAR 我们只取了行情与财报，未取公告全文/新闻
2. **知识截止**：回测起点 2010 时，任何现代 NLP 模型都 contaminated
3. **尺度不匹配**：文本信号半衰期约 5 日，我们标签 H=60
4. **成本**：实体对齐（改名/子公司/代码复用）需要长期维护一张映射表

**如果未来要做，最小可行路径**：
① 只取交易所公告（时点最干净）
② 只用词典法（无知识截止问题）
③ 做「叙事变化」而非情绪（手册实证支持）
④ 标签改 H=5（尺度匹配）
⑤ 承认覆盖率不足，用「有无公告」作 state 变量
