## 二、驱动假设（Driver Hypothesis）

| 因子 | 驱动类别 | 机制假设 | 方向 | 强度 | 失效条件 |
|---|---|---|---|---|---|
| `gm` | **风险补偿** | 风险补偿（质量溢价）：高毛利=竞争壁垒，市场对质量要求补偿 | + | 强 | 风险偏好反转时 IC 应下降 |
| `dgm_q` | **持续性** | 持续性：毛利率改善会延续（基本面动量），市场反应不足 | + | 中 | 震荡市 IC 应下降 |
| `transfer_intensity` | **持续性** | 持续性：产能在建工程转固→产能落地→营收增长是持续过程 | + | 中 | 产能过剩/需求不足时失效 |
| `dep_rate` | **持续性** | 持续性（弱）：资产老化→持续资本开支压力 | − | 弱 | 公司完成资产更新后失效 |
| `gm_vol` | **风险补偿** | 风险补偿（低波动异象）：投资者偏好彩票型，低估稳定股 | − | 中 | 风险偏好反转时 IC 应下降 |

**驱动分布**：风险补偿 2 个（gm、gm_vol）、持续性 3 个（dgm_q、transfer_intensity、dep_rate）、**均值回复 0 个、可预测时钟 0 个**。
说明因子集合同质化，组合分散效果有限——这是 F6 去重的重点，也是未来补因子的方向。

**可证伪性检查**：每个假设都能回答「如果错了会观察到什么」。
例如「毛利率不代表定价能力」→ 应观察到 IC ≈ 0。

**为什么必须有假设**：试 N 个无意义因子，H0 下 |t|>3 的期望个数 = N×0.0027。
N=1000 时会有 2.7 个「显著」，但它们样本外必然归零。

## 三、角色分离（Role Separation）

| 角色 | 变量 | 用法 |
|---|---|---|
| **signal** | `gm`, `dgm_q`, `transfer_intensity`, `dep_rate`, `gm_vol` | 进因子排序 |
| **state** | `industry_code`, `float_mv`, `st_flag`, `listed_days` | 分组/过滤，不进排序 |
| **label** | `label` | 预测目标 |

**为什么分开**：把行业当 signal 会让因子变成「选哪个行业」，不是「选哪只股票」。
state 只能用于 groupby（行业内排序）或过滤。

**重叠检查**：通过 ✅

## 四、改含义 vs 降噪

| 改动 | 分类 | 理由 |
|---|---|---|
| transfer_intensity 分母从 cip_prev 改为 fa_cost_begin | **改含义** | 分母从在建工程变成固定资产；经济含义从转固完成率变为投资强度 |
| 缩尾 1% → 0.5% | **降噪** | 只影响极端值处理 |
| MAD 3σ → 3.5σ | **降噪** | 同上 |
| 单季差分 → 累计同比 | **改含义** | 时间尺度改变 |
| 填中位数 → 填行业中位数 | **改含义** | 隐含行业内可比假设 |
| z-score → rank | **降噪** | 单调变换，秩不变 |

**纪律**：改含义 = 新实验，必须重跑全套并重新记账；
降噪 = 同假设，只需重跑评估。
