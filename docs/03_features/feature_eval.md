## ⚠️ 增量测试口径修正说明（后续同步）

本文档第五节的增量测试有两点后续已修正，以 `feature_governance.md` 第五节与 `signal_eval.md` 为准：

1. **原增量测试把 5 个因子混在一套合成里**（覆盖率 94~98% 与 19.8% 混用），导致高覆盖因子被低覆盖因子压制。
   修正：按覆盖率分组，各组分别做增量测试。
2. **合成口径由 IC 加权改为等权**。
   实测对比（2026-11-21）：全市场组等权 +0.0496 vs IC 加权 +0.0495；
   制造业组等权 +0.0592 vs IC 加权 +0.0622。
   **等权不劣且 p=0，故统一采用等权。**

**最终口径**：
```
全市场组：等权（gm_vol×−1 + dgm_q×+1 + gm×+1）/ 3     → IC +0.0496
制造业组：等权（transfer_intensity×+1 + dep_rate×+1）/ 2 → IC +0.0592
```
