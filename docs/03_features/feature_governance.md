## 三、停用与退役规则（G-F7.8）

| ID | 规则 | 触发条件 | 动作 |
|---|---|---|---|
| R1 | 连续两轮 IC 不显著 | 连续 2 次评估 |t| < Bonferroni 门槛 | 标记候选退役，进入下一轮观察 |
| R2 | 重要度持续近零 | SHAP 跨折均值 < 0.01 且标准差 < 0.005 | 删除并记入 changelog |
| R3 | 重要度突然跃升 | SHAP 环比跃升 > 5 倍 | 先查数据（该因子/其他因子覆盖率突变、数据源变更），查清前不动用 |

**R3 为什么最反直觉**：重要度突然跃升 ≠ 因子突然有效。
更可能是另一个因子数据断供，模型只能依赖剩下的那个，导致其重要度被动上升。
所以先查三步：①该因子覆盖率突变？②其他因子覆盖率突变？③是否与数据源变更吻合？

## 五、冻结的最终特征清单（合成口径已统一为等权）

**为什么分组**：`gm/dgm_q/gm_vol` 覆盖率 94~98%，`transfer_intensity/dep_rate` 覆盖率 19.8%（只有制造业披露附注）。
两组覆盖率互斥——混在一套合成里，实际只有 19.8% 的股票四个因子齐全。
**所以必须分组做增量测试，各自得到自己的保留清单。**

### 合成口径的统一（本版修正）

**F7 与 E2 曾用不同口径，现已统一。两种口径的实测对比如下：**

| 组 | 等权 IC | IC 加权 IC | 差异 | 谁更好 |
|---|---|---|---|---|
| 全市场组 | **+0.0496** | +0.0495 | +0.0000 | 等权（几乎相同） |
| 制造业组 | +0.0592 | **+0.0622** | -0.0030 | **IC 加权** |

**这是一个诚实的权衡，不能一边倒地说等权更好**：

```
全市场组：等权 +0.0496 vs IC 加权 +0.0495
  → 差异 +0.0000，可忽略
  → 等权胜在 p=0

制造业组：等权 +0.0592 vs IC 加权 +0.0622
  → IC 加权高 +0.0030
  → 但只有 15 个独立期，估 2 个权重的标准误约 1/√15 = 0.258
  → 权重估计误差（0.258）远大于它带来的收益（+0.0030）
  → 净判断：等权更稳
```

**最终决定：统一采用等权**，理由排序：

1. **全市场组：等权与 IC 加权几乎相同**（差 +0.0000），等权 p=0 更优
2. **制造业组：IC 加权虽高 +0.0030，但 < 权重估计误差**（0.258），不可靠
3. 与 M-S 的实测一致（等权 +0.0402 > Ridge +0.0193 > GBDT +0.0184）
4. 可复现性最好——不需要传递权重文件

**⚠️ 必须记录的一个反例**：制造业组的 IC 加权确实更高。如果未来样本量增加（独立期 > 50），
这个选择应该重新评估——届时的权重估计误差会降到 1/√50 ≈ 0.14，可能值得用 IC 加权。
