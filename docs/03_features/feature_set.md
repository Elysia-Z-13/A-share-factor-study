## 六、降维声明

**本项目不做 PCA 降维**。理由：
① 手册明确：PCA 先当风险分解与中性化工具，不要当 alpha 发生器
② 我们只有 5 个因子，降维收益很小
③ PC1 是市场 beta，用它当因子等于做多市场，不是 alpha

若未来做风险分解，BBP 阈值判断真实成分数：`1 + √γ`，γ = 特征数/样本数。
