# feature_price.md —— 价格衍生特征（F2）

## 一、五类构件

| 构件 | 本质 |
|---|---|
| **动量** | 过去涨得多→未来继续涨 |
| **反转** | 涨太多会回落（锚决定含义） |
| **波动** | 风险大小（必须方差型估计量） |
| **量价流动性** | 交易活跃度（右偏→取对数） |
| **技术指标组合** | 上面四类的组合，不带来新机制 |

## 二、本项目因子的归属（为什么几乎不做价格衍生）

| 特征 | 构件 | 说明 |
|---|---|---|
| `gm` | 基本面 | F3 范围，不在 F2 |
| `dgm_q` | 基本面 | F3 范围 |
| `transfer_intensity` | 基本面 | F3 范围 |
| `dep_rate` | 基本面 | F3 范围 |
| `gm_vol` | 波动（财务口径） | 波动构件的变体，用财务数据 |
| `mom_60` | 动量 | 对照因子 |
| `rev_5_ma60` | 反转 | 锚=MA60，偏离窗=5 日 |

**结论**：5 个主因子中 4 个属于「基本面」构件（不在 F2 范围），
只有 `gm_vol` 属于「波动」构件（但用财务数据而非价格）。
本项目**不产生价格衍生特征**，F2 的作用是方法论确认 + 防止未来引入时重复计数。

## 三、技术指标拆解（F2.2）

| 指标 | 公式 | 本质构件 |
|---|---|---|
| MACD | `EMA(12) − EMA(26)` | 动量（短窗−长窗） |
| RSI | `100 − 100/(1+涨幅/跌幅)` | 动量（归一化） |
| 布林带 %B | `(price−MA)/(2k·σ)+0.5` | 反转（锚=均线）+ 波动 |
| KDJ | `基于 RSV 的平滑` | 反转（锚=区间位置） |

**规则**：先能用构件表达，就不用指标；指标只作为变体，不额外带来机制。

**反向检查**：把技术指标当机制的条目 = 0 个 ✅

## 四、锚登记（F2.3）

| 特征 | 锚 | 锚窗口 | 偏离窗口 | 含义 |
|---|---|---|---|---|
| `rev_5_ma60` | MA60（60 日均线） | 60 | 5 | 短期偏离中期趋势 → 反转构件 |

**为什么锚窗口与偏离窗口要分开**：
若同窗口，`price/MA60−1` 测的是「60 日反转」；分开后测「短期偏离中期趋势」。

## 五、波动估计量（F2.4）

| 估计量 | 公式 | 相对效率 | 说明 |
|---|---|---|---|
| 收盘价标准差 | `std(daily_ret, T)` | 1× | 基准 |
| Parkinson | `sqrt(mean(ln(H/L)²)/(4ln2))` | 5× | 用日内高低 |
| Garman-Klass | `0.5ln(H/L)²−(2ln2−1)ln(C/O)²` | 7× | 加开收盘 |
| Yang-Zhang | `组合估计量` | 8~14× | 处理跳空与趋势 |
| ATR | `mean(|H−L|,|H−C_prev|,|L−C_prev|)` | N/A | ❌ 绝对变动均值，不是方差估计量，不能当波动率 |

**本项目选择**：方差型估计量（`std`）。
明确排除 ATR —— 它是绝对变动的均值，单位是「元」，
直接比较会让高价股被误判为高波动。
