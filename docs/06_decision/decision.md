**⚠️ 一条已经触发的**：

```
E7 实测 MDD −53.7% 已超过 E6 的 K4 kill 阈值（−52.4%）
→ 意味着若按 K4 部署，回测期本身就触发过一次 kill
→ 这是 D1 之外的另一个警示信号
```

**为什么必须写这些**：

```
没有死亡条件的研究永远不会死

```

## 十一、这次研究最有价值的三件事

**这三件事比「策略是否成立」更重要。**

### ① 时限错配会在 timing placebo 上暴露

```
F0 的时限检查：附注因子是年报数据，4 倍错配
        ↓
E1 的 timing placebo：远处滞后 IC 不衰减甚至更强（k3 +0.0535 > k0 +0.0449）
        ↓
E1 裁决：STOP（慢变状态代理，不是信息驱动）
```

**这条链说明**：时限对齐不是形式主义——错配的因子会在机制检验上留下指纹。
而唯一时限对齐正确的 `dgm_q`，也是唯一 4/4 全过的因子。

### ② 口径漂移比算法错误更难发现

```
同一个组合，三个文档三个 IC：0.0402 / 0.0512 / 0.0496
排查发现是 rank 的作用域不同（折内 / 整面板 / 期内）
三者都不报错、都不荒谬，只在交叉核对时暴露
```

**建了 `metric_spec.md` 把唯一算法固定下来**，并总结了五种常见口径漂移。

### ③ 空头端的 alpha 拿不到，这不是细节

```
dgm_q 的多空价差 +1.421%
但多头超额只有 +0.136%（空头占 90%）
组合：多空 +2.783%，多头超额 +0.777%（空头占 72%）

E2 的名义多头超额 0.777%/期
→ E4 扣成本、加 cohort、剔涨停后只剩 0.44%/期
→ E5 用真实 20.9bp 成本后净超额 +1.26%/年
```

**如果把多空价差当收益，会高估 3~10 倍。**

## 十二、最终裁决

**再研究（REVISE）。**

| 维度 | 结论 |
|---|---|
| **是否有效** | 点估计为正（净超额 +1.26%/年），但 **DSR 0.8153 = 证据不足** |
| **是否可交易** | 可交易，但**规模上限 2141 万** |
| **是否稳健** | 压力 5/8、衰减明显（2021-2024 净超额趋零） |
| **建议** | **不投入资金**；优先试「剔除小盘档」以同时解决容量与 alpha 质量；补 parity 与暴露归因后再评估 |

**最诚实的一句话**：

> 我们做出了一个**统计上无法确认、规模上受限、但各处证据方向一致**的因子。
> 用 17 年、15 次试验的数据，我们无法把「可能」升级成「确定」。
> 而那四条 STOP 条件一条都不满足，说明它也不该被判死。
> 所以答案只能是：**再研究**。
