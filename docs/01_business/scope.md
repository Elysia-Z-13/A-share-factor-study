## 一、决策问题（G-B0.2）

**月度调仓，在全市场 A 股中，选出未来 60 个交易日能跑赢等权基准的股票。**

| 要素 | 定义 |
|---|---|
| 频率 | 月度调仓（每 20 个交易日形成一次持仓），持有 60 个交易日 |
| 标的 | 全市场 A 股（主板 / 创业板 / 科创板 / 北交所），剔除停牌与涨停买不进 |
| 决定 | 横截面选股：买入评分最高的 30%，等权持有 |
| 基准 | 同池等权（不是指数，避免指数编制规则干扰） |
| 标签 | `label = close_adj[t+60] / close_adj[t] − 1` |

**为什么 H = 60**：本项目因子基于季度财报，每 60 个交易日与一次财报更新对齐。用 20 日标签会造成 3 次"无新信息的重复检验"。

## 二、信息集（G-B0.3）

**决策日 T 收盘后可知的全部字段：**

| 数据 | 字段 | 发布延迟 | 可用时点 |
|---|---|---|---|
| 日频行情 | open/high/low/close/close_adj/volume/amount | 0 | T 日收盘后 |
| 复权因子 | adj_factor | 0 | T 日收盘后 |
| 涨跌停价 | limit_up / limit_down | 0 | T 日开盘前 |
| 交易状态 | trade_status（含 ST 标记 2/3/6） | 0 | T 日收盘后 |
| 流通市值 | float_mv | 0 | T 日收盘后 |
| **财务报表** | revenue / cogs / fa_net / cip / transfer_from_cip / dep_add | **见下** | **公告日 announce_date** |
| 申万行业 | industry_code | 变更时 | 变更实施日 |

**财务报表的时点纪律（最关键）**：

```
可用条件：DeclareDate ≤ T
取满足条件中 accper 最大的一份
```

**绝不使用**：报告期（accper）当可用时点。2024 年报要到 2025-04 才公布，用 2024-12-31 当可用时点就是前视。

**公告日缺失处理**：若 DeclareDate 为空，则**不使用**该记录（不用"报告期 + 90 天"兜底，宁可丢样本也不引入前视）。

## 三、收益来源（G-B0.4）

**六类 edge 中选择：定价错误（Mispricing）**

| 六类 edge | 本项目 |
|---|---|
| 信息优势 | ❌ 无另类数据 |
| 执行优势 | ❌ 无低延迟通道 |
| **定价错误** | ✅ **市场对基本面边际变化反应不足** |
| 风险溢价 | ❌ 不做风险因子建模 |
| 制度约束 | ❌ |
| 结构性 | ❌ |

**机制叙事**：

财务报表里有两类信息被市场系统性低估：

1. **固定资产的边际变化**（转固率、折旧率）——市场关注利润表，忽视资产负债表附注
2. **毛利率的异常变化**（剔除规模效应后）——单季度毛利率变化在季报里被淹没在年度数据中

**反应不足的成因**：
- 附注信息（固定资产明细）需要手工整理，机构覆盖成本高
- 季度频率下，单季毛利率需要自己差分计算，不是现成指标
- 信息分散在 5 张表里，需要拼接

## 四、策略族（G-B0.7）

**横截面多因子（long-only）**

| 维度 | 选择 |
|---|---|
| 多空 | 仅多头（A 股融券成本高、券源少） |
| 权重 | 等权（不用市值加权，避免大盘股权重过大） |
| 选股比例 | 前 30%（约 1600 只，兼顾分散与信号强度） |
| 调仓 | 月度（每 20 交易日） |
| 持有 | 60 交易日（3 个月，标签对齐） |
| 行业中性 | 是（行业内排序，避免行业 beta） |

**可行性过滤器（族 = 过滤器）**：

```
① 必须有财报数据（否则无法构造因子）
② 剔除金融股（银行/保险没有在建工程、营业成本）
③ 剔除停牌
④ 剔除入场日涨停（买不进）
⑤ 剔除上市不满 250 日（无历史波动率）
```

## 五、成本量级（G-B0.8）

| 项目 | 假设 | 依据 |
|---|---|---|
| 佣金 | 2.5 bp（单边） | 万分之 2.5，主流券商 |
| 印花税 | 5 bp（卖出） | 法定 0.1%，单边 |
| 过户费 | 0.1 bp | 万分之 0.1 |
| **单边成本合计** | **10 bp** | 买 2.5 + 卖 7.6 ≈ 10 |
| 滑点 | 含在上面 | 小市值可能更高，做敏感性测试到 30 bp |

**成本敏感性**：要做 5 / 10 / 15 / 20 / 30 bp 五档。

**持有期与成本的关系**：

```
月换手 30% → 年化换手 360%
年化成本 = 360% × 2 × 10bp = 7.2%
```

**这意味着因子年化超额必须 > 7.2% 才值得做。**
若达不到，必须靠**降低换手**（季度调仓）或**提高持有期**来压缩成本。

## 六、Stop Criteria（G-B0.5）

**三条可观测的放弃条件：**

| # | 条件 | 观测方式 | 触发即停 |
|---|---|---|---|
| **1** | 样本外（2025 起）Sharpe < 0.5 | 月度滚动计算 | 是 |
| **2** | 盈亏平衡成本 < 20 bp | `gross / (2 × turnover)` | 是 |
| **3** | 市值或行业暴露 > 2× | 组合 vs 全市场分布 | 是 |

**附加的软条件（记录但不强制停）**：

- 连续 12 个月超额为负
- IC 滚动 12 月均值为负且 t < −2

## 七、四问判定（G-B0.6）

**① 族与节奏**

```
族：横截面多因子（long-only）
节奏：月度调仓 + 60 日持有（重叠持有 3 个 cohort）
→ 有效持仓数 ≈ 3 × 1600 = 4800 只（几乎全市场）
→ 实际更像"全市场 tilt"而非"精选"
```

**② PnL 分解**

```
收益 = 市场 beta × 1.0
     + 因子暴露带来的超额（本项目的目标）
     − 交易成本
     − 冲击成本（小市值更高）
```

**预期分解**：市场 beta 贡献 90%+ 的波动，因子超额贡献 5-15% 的收益。

**③ edge 叙事**

见「三、收益来源」。

**④ Top 失败模式（按可能性排序）**

| # | 失败模式 | 后果 | 缓解 |
|---|---|---|---|
| **1** | **因子已被套利抹平** | 样本外 Sharpe ≈ 0 | 严格样本外检验 |
| 2 | 数据口径错误（复权/涨跌停/PIT） | 造出假 alpha | 逐项校验 + 对照年报 |
| 3 | 小市值集中 | 超额是小盘 beta | 市值暴露检查 |
| 4 | 换手过高 | 成本吃掉超额 | 换手约束 + 成本敏感性 |
| 5 | 财报覆盖不足 | 样本少、结论不稳 | 记录覆盖率 |
| 6 | 前视偏差 | 成绩虚高 | PIT 合并 + 前视检查 |

## 八、耐久性（G-B0.9）

**为什么这个收益来源会持续？**

| 支撑 | 论证 | 衰减风险 |
|---|---|---|
| **信息加工成本** | 附注数据需手工拼接，机构覆盖不全 | 中：数据商开始提供后会被抹平 |
| **容量约束** | 小市值股票容量有限，大资金进不去 | 低：这是结构性约束 |
| **注意力稀缺** | 市场聚焦利润表，忽视资产负债表附注 | 中高：随量化普及而衰减 |
| **季度频率** | 财报一年只更新 4 次，信息释放慢 | 低：制度性 |

**诚实的判断**：

> 定价错误类因子**必然衰减**。历史上 A 股基本面因子的半衰期约 3-5 年。
> 因此本项目必须建立**滚动监控**：每季度重估一次 IC，IC 连续 4 季度下降即降低权重。
> 不假设任何因子永久有效。

## 九、预期校准（G-B0.10）

| 指标 | 目标 | 依据 |
|---|---|---|
| **Rank IC** | **0.02 ~ 0.05** | 单因子在 A 股的正常水平 |
| 年化超额 | 2% ~ 8% | IC 0.03 × 年化波动 25% × √12 ≈ 2.6% |
| **Sharpe（超额）** | **0.5 ~ 1.2** | 好因子 1.0 左右，超神不存在 |
| 最大回撤（超额） | < 15% | 与 Sharpe 相关 |
| 换手 | < 40% / 月 | 超过则成本吃掉收益 |

**明确不追求**：
- Sharpe > 2（在 A 股 long-only 上不现实）
- IC > 0.1（有这个就不叫因子了）
- 年化 > 20% 的稳定超额
