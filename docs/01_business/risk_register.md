## 三、数据（断源与许可到期）

### 3.1 断源风险

| 项 | 评估 |
|---|---|
| 数据获取方式 | 一次性批量下载，本地存档（`DATA/` 原始 + `CLEAN/` 清洗结果） |
| 是否依赖实时接口 | ❌ 不依赖。研究可离线完成 |
| 断源影响 | **低**。已有数据可支撑完整研究 |
| 但如果要更新 | 需要重新登录 CSMAR 下载，无法自动增量 |

**结论：断源风险低，但更新不可自动化。**

### 3.2 许可到期风险

```
学校订阅到期 → 无法继续下载新数据
→ 已有数据仍可使用（已存档）
→ 但无法扩展到 2026 年以后
→ 若写进论文，需注明数据截止日期
```

### 3.3 已知数据质量风险（已量化）

| 风险 | 实测值 | 处置 |
|---|---|---|
| 幸存者偏差 | `listing.csv` 含 **315 只退市股** | ✅ 已处理 |
| 停牌日缺失 | CSMAR 停牌日整行缺失（非 volume=0） | ✅ universe reindex 补齐 |
| 覆盖率断崖 | 最差年跌幅 **0.55%** | ✅ 无断崖 |

## 六、模型（失效与衰减）

### 6.1 失效风险

| 风险 | 表现 | 已定的处置 |
|---|---|---|
| 因子被套利抹平 | 样本外 IC 持续下降 | **stop criteria**：IC < 0.015 立即停止 |
| 过拟合 | 训练 IC 高、测试 IC 低 | 过拟合度 > 0.6 即淘汰模型 |
| 前视偏差 | IC 异常高（> 0.1） | PIT 合并 + 前视检查（0 容忍） |
| 多重检验 | 试多次后最好那个显著 | Bonferroni 校正，N 从 trial 账本取 |
| 结构变化 | 注册制、涨跌停改革 | universe 与涨跌停规则按日期分段 |

### 6.2 已知的模型局限（报告中必须声明）

| 局限 | 说明 |
|---|---|
| 财务明细覆盖不足 | 转固率/折旧率仅覆盖 17~20% 的股票 |
| 样本外期短 | holdout 仅 23 个月（数据到 2026-11） |
| 独立时间点少 | H=60 → 16 年只有约 66 个独立观测 |
| 不建模风险因子 | 未做 Barra 风格中性化，只做了行业中性 |

**结论：模型风险有明确的止损条件与披露清单，无「说不清」项。**
