## 二、字段契约（核心）

### 2.1 主键

| 字段 | 来源 | 单位 | 何时可得 | 用途 |
|---|---|---|---|---|
| `code` | TRD_Dalyr.Stkcd | 6 位字符串 | — | 主键 |

### 2.2 价格类（必须区分复权与未复权）

| 字段 | 来源 | 单位 | **何时可得** | 用途 |
|---|---|---|---|---|
| `open` | TRD_Dalyr.Opnprc | 元（未复权） | **T 日 09:30**（集合竞价结束） | 算复权开盘价 |
| `high` | TRD_Dalyr.Hiprc | 元（未复权） | **T 日 15:00** | 振幅（本项目未用） |
| `low` | TRD_Dalyr.Loprc | 元（未复权） | **T 日 15:00** | 振幅（本项目未用） |
| `close` | TRD_Dalyr.Clsprc | 元（未复权） | **T 日 15:00** | 算复权因子、比涨跌停 |
| `close_adj` | TRD_Dalyr.Adjprcwd | 元（复权） | **T 日 15:00** | **算收益、波动、标签** |
| `open_adj` | 派生：`open × (close_adj/close)` | 元（复权） | **T 日 15:00** | **T+1 开盘买入价** |

**⚠️ 复权与未复权的使用边界（最重要的口径）**

| 场景 | 用哪列 | 反例（会错） |
|---|---|---|
| 算收益 / 标签 / 波动 | `close_adj` / `open_adj` | 用 `close` → 除权日假跌 |
| 判断涨跌停 | `close`（未复权） | 用 `close_adj` → 判断全错 |
| 算市值 | `close × 股本`（未复权） | 用复权价 → 市值虚高 |
| 复权因子 | `close_adj / close` | — |

**为什么涨跌停必须用未复权价**：

```
交易所按「未复权收盘价 × (1 ± 幅度)」定涨跌停
除权日：复权价连续，但未复权价跳空
→ 用复权价比涨跌停，会漏掉大量真实涨跌停
→ 实测错误率可达 40%
```

### 2.3 成交量与市值

| 字段 | 来源 | 单位 | **何时可得** | 用途 |
|---|---|---|---|---|
| `volume` | TRD_Dalyr.Dnshrtrd | **股** | **T 日 15:00** | 换手率、停牌判定 |
| `amount` | TRD_Dalyr.Dnvaltrd | **元** | **T 日 15:00** | 容量估算（ADDV） |
| `float_mv` | TRD_Dalyr.Dsmvosd | **千元** | **T 日 15:00** | 市值暴露检查 |
| `total_mv` | TRD_Dalyr.Dsmvtll | **千元** | **T 日 15:00** | 市值暴露检查 |

**单位核对（必须做，不能猜）**：

```
验证方法：总市值 / 总股本 ≈ 当日收盘价
若差 1000 倍，说明单位是千元
```

**本项目实测**：`Dsmvosd` / `Dsmvtll` 单位为**千元**，使用时需 ×1000 转元。

### 2.4 交易约束

| 字段 | 来源 | 单位 | **何时可得** | 用途 |
|---|---|---|---|---|
| `limit_up` | 派生：`round(前收盘 × (1+幅度), 2)` | 元 | **T 日 09:15** | 判断能否买入 |
| `limit_down` | 派生：`round(前收盘 × (1−幅度), 2)` | 元 | **T 日 09:15** | 判断能否卖出 |
| `hit_limit_up` | 派生：`|close − limit_up| < 0.005` | 布尔 | **T 日 15:00** | mask 剔除 |
| `trade_status` | TRD_Dalyr.Trdsta | 枚举 | **T 日 09:15** | ST 判定、停牌 |
| `st_flag` | 派生：`trade_status ∈ {2,3,6}` | 0/1 | **T 日 09:15** | 剔除 ST |
| `suspended` | 派生：该日无行情记录 | 布尔 | **T 日 15:00** | universe 标记 |

**涨跌停幅度的决定规则（按优先级，先命中先停）**：

| 优先级 | 条件 | 幅度 |
|---|---|---|
| 1 | `trade_status ∈ {2,3,6}`（ST/*ST） | **5%** |
| 2 | 代码 688 开头（科创板） | 20% |
| 3 | 代码 300/301 且 `date ≥ 2020-08-24` | 20% |
| 4 | 代码 300/301 且 `date < 2020-08-24` | 10% |
| 5 | 代码 8/4 开头（北交所） | 30% |
| 6 | 其余（主板） | 10% |
| 7 | 上市首日 | 无限制（本项目剔除） |

**ST 判定依据（已用 2023 年数据交叉验证）**：

| Trdsta | 落在 ST 期内的比例 | 结论 |
|---|---|---|
| 2 | 100.00% | ST |
| 3 | 98.58% | *ST |
| 6 | 100.00% | ST |
| 1 | 0.00% | 正常 |

### 2.5 财务报表（**PIT 最敏感**）

| 字段 | 来源 | 单位 | **何时可得** | 用途 |
|---|---|---|---|---|
| `end_date` | FS_Comins.Accper | YYYY-MM-DD | **不可用于决策** | 报告期，仅作匹配键 |
| `ann_date` | FS_Comins.DeclareDate | YYYYMMDD | **公告日当天** | **PIT 对齐键** |
| `if_correct` | FS_Comins.IfCorrect | 0/1 | 公告日当天 | 更正版本判定 |
| `typrep` | FS_Comins.Typrep | A/B | 公告日当天 | A=合并报表（只用 A） |
| `revenue` | FS_Comins.B001101000 | 元 | **公告日盘后** | 营业收入 |
| `cogs` | FS_Comins.B001201000 | 元 | **公告日盘后** | 营业成本 |
| `gm` | 派生：`(revenue−cogs)/revenue` | 比率 | **公告日盘后** | 毛利率 |
| `dgm_q` | 派生：单季毛利率差分 | 比率 | **公告日盘后** | 异常毛利率原料 |
| `fa_net` | FS_Combas.A001212000 | 元 | **公告日盘后** | 固定资产净额 |
| `cip` | FS_Combas.A001213000 | 元 | **公告日盘后** | 在建工程 |
| `total_asset` | FS_Combas.A001000000 | 元 | **公告日盘后** | 总资产 |
| `transfer_from_cip` | FN_Fn020.Fn02007（类型1） | 元 | **公告日盘后** | 在建工程转入 |
| `fa_cost_begin` | FN_Fn020.Fn02003（类型1） | 元 | **公告日盘后** | 固定资产原值期初 |
| `dep_add` | FN_Fn020.Fn02004（类型2） | 元 | **公告日盘后** | 折旧计提 |

**`end_date` 绝不能当可用时点（最关键的一条）**

```
❌ 错误：2024-12-31 的报告期，2025-01-02 就用
✅ 正确：等 declare = 2025-04-25 之后才能用
```

**PIT 对齐规则**：

```
在决策日 T，可用信息 = { 报表 r : r.ann_date ≤ T }
取其中 r.end_date 最大的一份
if_correct：同一 (code, end_date) 有多份时，取 ann_date 最大的
typrep：只保留 A（合并报表）
```

**公告日缺失的处理**：

```
若 ann_date 为空 → 丢弃该记录
不用「报告期 + 90 天」兜底
理由：兜底日可能早于真实公告日 → 前视
代价：损失约 2% 的样本
```

## 三、三大口径确认（G-D0.4）

| 口径 | 本项目的选择 | 理由 |
|---|---|---|
| **价格复权** | 双列并存：`close`（未复权）+ `close_adj`（复权），**按用途分别使用** | 涨跌停必须用未复权；收益必须用复权 |
| **成交量单位** | **股**（`Dnshrtrd`） | CSMAR 原始单位；换手率 = volume / 流通股 |
| **市值口径** | **流通市值（千元 → 需 ×1000）** | 与换手率、容量计算口径一致 |
| **行业分类** | **申万 2021 版一级（31 个）** | 覆盖 98.2% 的股票，历史归属可重建 |

## 四、字段可用时点的代码实现

```python
# ① 行情：全部为 T 日 15:00 后可知
quote_fields = ["open","high","low","close","close_adj","volume","amount","float_mv"]

# ② 交易约束：T 日盘前可知（用前收盘算）
limit_fields = ["limit_up","limit_down","st_flag","trade_status"]

# ③ 财报：只用 ann_date ≤ T 的记录
def pit_merge(daily, fin):
    return pd.merge_asof(
        daily.sort_values("date"),
        fin.sort_values("ann_date")[["ann_date","end_date","gm","dgm_q",...]],
        left_on="date", right_on="ann_date",
        direction="backward",      # 只取「公告日 ≤ 当天」
    )

# ④ 前视检查
assert (merged["ann_date"] > merged["date"]).sum() == 0
```
