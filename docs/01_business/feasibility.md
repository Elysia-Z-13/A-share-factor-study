# feasibility.md —— 可行性（B2）

> 结论：**可行性暂不判定，推迟到 E5 回测后实测。**
> 原因：可行性算术的核心输入是 IC（信号强度），而因子尚未构造、IC 尚未测量。
> 在没有信号的阶段算成本倍数，只是把假设当结论。这属于「假精确」，比不写更有害。

---

## 一、cadence 三区定位（G-B2.6）

| 区 | 频率 | 判断 | 理由 |
|---|---|---|---|
| **硬地板** | 日频 | 不可行 | 单边 10bp × 每日换手，成本是毛收益的数百倍 |
| **灰色地带** | 月频（H=20） | 勉强 | 财务因子每月只变 1/3，换手浪费在无新信息上 |
| **舒适区** | **季频（H=60）** | **本项目** | 与财报更新节奏对齐，一年 4 次检验 |

**本项目的定位：季频（H = 60 个交易日）**

选择依据：

```
财报一年更新 4 次
→ 因子每 60 个交易日才有新信息
→ 用 20 日标签会造成 3 次"无新信息的重复检验"
→ 用 60 日标签与信息释放节奏对齐
```

## 二、为什么暂不算成本倍数（G-B2.2）

成本倍数公式：

```
倍数 = 毛收益（每期） / 往返成本（每期）
     = [IC × σ_cross(H) × avg_z] / [换手率 × 2 × 单边成本]
```

**三个输入的状态**：

| 输入 | 状态 | 说明 |
|---|---|---|
| `IC` | **未知** | 因子未构造，IC 未测量。文献值 0.02~0.05 只能当参考，不能当结论 |
| `σ_cross(H)` | 可测 | 从行情数据可算，已知约 12%（H=60） |
| `avg_z` | 已知 | 前 30% 约 1.16（正态分布性质） |
| 换手率 | **未知** | 取决于因子自相关，只有构造出来才知道 |

**4 个输入里 2 个未知** → 算出来的倍数是假的。

**推迟位置**：E5（成本评估）会用实测 IC 和实测换手重算这个倍数。

## 三、为什么暂不算容量（G-B2.3 / G-B2.4）

容量公式：

```
容量 = 组合总 ADDV × 参与率上限
目标资金 ≤ 容量 / 2
```

**同样依赖未知量**：

```
组合总 ADDV 取决于「选出哪些股票」
→ 而选出哪些股票取决于因子排序
→ 因子未构造 → 无法确定组合的 ADDV 分布
```

**唯一可以先算的**：全市场日均成交额（不依赖因子）。

**推迟位置**：E6（换手、容量与 kill）会用实际持仓重算。

## 四、制度约束（G-B2.5）

**这一条不依赖因子，现在就能定。**

| 约束 | 具体规则 | 对本策略的影响 | 已处理？ |
|---|---|---|---|
| **T+1** | 当日买入次日才能卖 | 持有 60 日，无影响 | ✅ 天然满足 |
| **涨跌停** | 主板 10% / ST 5% / 创业板科创板 20% / 北交所 30% | 涨停日买不进 | ✅ `hit_limit_up` 已剔除标签 |
| **不能做空** | 融券券源少、费率 8~10% 年化 | 只能 long-only | ✅ 策略为 long-only |
| **印花税** | 卖出 0.1% | 计入成本 | ✅ 单边 10bp 含 |
| **ST 股** | 涨跌幅 5%，退市风险 | 波动结构不同 | ⏳ **待决定**：剔除还是保留 |
| **次新股** | 上市首日无涨跌幅限制 | 收益异常 | ✅ 剔除前 250 日 |
| **停牌** | 停牌期间无法交易 | 无法成交 | ✅ universe 已标记 suspended |
| **退市** | 退市整理期无法正常交易 | 幸存者偏差 | ✅ listing 已含 315 只退市 |

**两个待决策项**：

```
① ST 股（Trdsta ∈ {2,3,6}）
   剔除 → 更干净，但样本少约 5%
   保留 → 样本多，但 5% 涨跌幅会扭曲信号
   本项目选择：剔除（理由：财务因子在 ST 股上不可信，且 ST 多已亏损）

② 北交所（代码 8/4 开头）
   纳入 → 样本多约 360 只
   剔除 → 更保守（流动性差、涨跌幅 30%）
   本项目选择：纳入，但在 E6 单独检查容量贡献
```

## 五、结论

| 检查项 | 状态 |
|---|---|
| cadence 三区定位 | ✅ 季频（舒适区） |
| 制度约束 | ✅ 八条已列，两个待决策项已定 |
| 毛收益 / 成本倍数 | ⏸ **推迟到 E5**（IC 未测） |
| 容量 | ⏸ **推迟到 E6**（持仓未知） |
| 目标资金 | ⏸ **推迟到 E6** |

**这不是跳过质量检查，而是把它挪到有数据的时点。**

B2 的设计意图是「在投入大量工作前先做一次粗筛」。但粗筛的输入是信号强度，
而本项目采用**自下而上**的路径：先构造因子 → 测 IC → 再判可行性。

**代价**：如果最终 IC < 0.01，前面 D/F 段的工作就白做了。
**接受这个代价的理由**：没有别的办法能在构造因子之前知道 IC。

---

## 六、如果 IC 出来后不满足，怎么止损

| 实测 IC | 结论 | 行动 |
|---|---|---|
| ≥ 0.03 | 可行 | 继续到 E4/E5 |
| 0.015 ~ 0.03 | 边缘 | 检查换手，若 < 50% 可继续 |
| < 0.015 | 不可行 | 停止，把负结果写进报告 |

**止损点是 E2（信号评估），不是 E5。** 一旦 E2 测出 IC < 0.015，立刻停止，不进 E4。
