## 四、指标冲突与裁决（G-V.4）

| 冲突 | 现象 | 裁决 | 依据 |
|---|---|---|---|
| IC 显著但测试段转负 | 置换 p=0.000 但 G2 测试 IC -0.0118 | **以分层/时序为准** | 手册：稳定 > 峰值；分层 > 池化 |
| 等权优于拟合模型 | M-S：等权 +0.0402 > Ridge +0.0193 | **保留等权** | 零参数不引入新的过拟合风险 |
| DSR 通过但因子衰减 | DSR 1.0000 但 2022-2024 转负 | **以衰减为准，降低置信** | 手册：经济含义 > 统计显著性 |

**裁决原则（手册原话）**：
> 经济含义 > 统计显著性；成本后 > 成本前；分层 > 池化；稳定 > 峰值。
> 两个指标打架时**同时报两个**，并写明取舍依据。

## 五、置换检验（同日内打乱，200 次）

| 组 | 真实 IC | 零分布均值 | 零分布 std | 零分布 p95 | p 值 |
|---|---|---|---|---|---|
| 全市场组 | **+0.0512** | -0.0000 | 0.0023 | +0.0037 | **0.000** |
| 制造业组 | **+0.0613** | -0.0010 | 0.0051 | +0.0074 | **0.000** |

**为什么必须在同日内打乱**：
```
市场层面的收益（今天大盘涨）是共有的
全样本随机打乱 → 破坏截面结构 → 打乱后 IC 必然 ≈ 0 → 检验失效
同日内打乱 → 保留「哪天涨哪天跌」，只打乱「哪只股票」
→ 这样才检验「真正的选股能力」，而不是「跟着大盘涨」
```

**结论**：真实 IC 远高于零分布 p95，p=0.000 → **不是运气**。
这是本步最正面的结果：模型确实学到了截面信息。

## 六、trial 数与 DSR（G-V.5）

**trial 账本**：14 条（见 `mlft log`）

### 公式与修正

```
DSR = Φ[ (SR − SR_0) × √(T−1) / √(1 − γ3·SR + ((γ4−1)/4)·SR²) ]
SR_0 = √(V_SR) × [ (1−γ)·Φ⁻¹(1−1/N) + γ·Φ⁻¹(1−1/(N·e)) ]
     V_SR = 1/(T−1)（零假设下的 Sharpe 估计方差）
```

**⚠️ 一个常见错误（我第一版就犯了）**：
```
错误：SR_0 = √(2 ln N)                 → N=14 时 = 2.30
正确：SR_0 = √(2 ln N / (T−1))         → T=70 时 ≈ 0.21

错误版本的后果：门槛被抬到 2.30，任何策略都不可能通过
→ 这不是「严格」，是「算错」
```

### 实测

| 组 | 估算 Sharpe | SR_0 | DSR | 判定 |
|---|---|---|---|---|
| 全市场组 | +0.874 | 0.209 | **1.0000** | ✅ >0.95 |
| 制造业组 | +1.047 | 0.465 | **0.9601** | ✅ >0.95 |

### ⚠️ DSR 余量不足的诚实评估

**DSR 1.0000 在数学上正确，但输入有三个乐观假设：**

| # | 假设 | 实际 | 影响 |
|---|---|---|---|
| ① | Sharpe = 0.874 是回测值 | 它是 `IC/σ_IC × √(252/H)` 的**估算**，未扣成本/换手/集中度 | 真实 Sharpe 更低 |
| ② | N = 14 | 实际搜索次数更多（5 因子 × 变换 ≈ 15、8 个模型 ≈ 8、2 种对齐、2 种去重阈值 ≈ **> 29**） | 门槛应更高 |
| ③ | **T = 70 是独立观测数** | H=60 重叠，真实年化独立观测 = 70 × 60/250 ≈ **17** | **影响最大** |

**按 T = 17 重算（全市场组）**：

```
SR_0 = √(1/16) × [(1−γ)Φ⁻¹(1−1/14) + γΦ⁻¹(1−1/(14e))]
     = 0.25 × [0.4228×2.077 + 0.5772×1.926]
     = 0.25 × 1.990 = 0.498
z    = (0.874 − 0.498) × √16 = 0.376 × 4 = 1.504
DSR  = Φ(1.504) = 0.933     ← 跌破 0.95 门槛
```

**结论**：

```
DSR 按 M-V 的标准（T=期数）通过（1.0000）
但按更严格的口径（T=年化独立观测）不通过（0.933）
→ DSR 通过但余量不足，不应作为主要证据
→ 分年 IC 的衰减趋势才是更可信的判断依据
```

**Sharpe 的估算方式（必须披露）**：
```
Sharpe ≈ IC / σ_IC × √(252/H)
这是「多空等权组合」的粗略近似，不是真实回测
真实 Sharpe 要在 E4 用净值算，本步只是提前量
```

## 七、回退决定（G-V.7）

**是否回退：不回退。**

**理由**：
```
① G2 全市场组不过，但「不过」的原因是因子衰减，不是模型太复杂
   → 我们已经用最简模型（零参数），没有更简的可退
   → 回退到 M-S 没有意义（M-S 的结论就是选最简单那个）

② 真正该做的是「降低置信度并记录失效条件」，交给 E2/E7 裁决
   → 手册诊断手册：「以上全排除仍落后 → 不用它，把这次记成负结果写进 runlog」
```

**记录失效条件**：
```
全市场组：2022 年起 IC 连续为负（2022 −0.041、2023 −0.034、2024 +0.018）
         → 失效条件：A 股机构化提速 / 财务因子被充分定价
制造业组：2022-2023 连续为负（−0.028、−0.029），2024 无数据
         → 失效条件：制造业产能周期反转
```

**若必须回退，退哪里**：
```
退到 F7（删因子）：若 E2 确认全市场组失效 → 只保留制造业组
退到 F0（重新审视机制）：若两组都失效 → 重新找驱动假设
```
