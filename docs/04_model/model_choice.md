## D′｜Ridge vs GBDT 实测（硬门槛）

手册硬门槛：**非线性必须显著胜出（折级 IC 置信区间不重叠）；IC 提升 < 0.003 一律不算赢。**

### 全市场组

| 模型 | 折级平均 IC | 标准差 | 折数 | 各折 IC |
|---|---|---|---|---|
| ridge | +0.0193 | 0.0322 | 5 | [-0.0041, 0.0348, 0.07, -0.0233, 0.0192] |
| gbdt | +0.0201 | 0.0264 | 5 | [-0.0044, 0.03, 0.0495, -0.0176, 0.0428] |
| equal | +0.0402 | 0.0522 | 5 | [0.103, 0.0309, 0.0974, -0.0247, -0.0054] |

- GBDT − Ridge = **+0.0007**（门槛：需 > 0.003 且置信区间不重叠）
- Ridge − 等权 = **-0.0209**

**判定：GBDT 相对 Ridge 的提升 +0.0007 < 0.003，不构成胜出 → 不采用非线性。**

### 制造业组

| 模型 | 折级平均 IC | 标准差 | 折数 | 各折 IC |
|---|---|---|---|---|
| ridge | +0.0556 | 0.0322 | 5 | [0.0832, 0.0601, 0.0755, 0.0662, -0.0069] |
| gbdt | +0.0377 | 0.0366 | 5 | [-0.0236, 0.0652, 0.065, 0.0675, 0.0141] |

- GBDT − Ridge = **-0.0180**（门槛：需 > 0.003 且置信区间不重叠）
- Ridge − 等权 = **+0.0342**

**判定：GBDT 相对 Ridge 的提升 -0.0180 < 0.003，不构成胜出 → 不采用非线性。**

|---|---|---|---|

### 三个结论

**① 我手写的 MiniGBDT 与 sklearn 的 GBDT 几乎一致**

```
MiniGBDT +0.0201（全市场） vs sklearn GBDT +0.0184
MiniGBDT +0.0377（制造业） vs sklearn GBDT +0.0494
```

差异在正常波动内，说明手写实现没有系统性偏差。

**② 非线性仍然未胜出（硬门槛）**

```
全市场：最优非线性 minigbdt +0.0201 vs Ridge +0.0193
       ΔIC = +0.0007  （门槛需 > 0.003）

制造业：最优非线性 gbdt_es +0.0540 vs Ridge +0.0556
       ΔIC = -0.0016  （门槛需 > 0.003）
```

**两组的 ΔIC 都远小于 0.003 → 非线性不采用，结论确认。**

**③ 全市场组：零参数的等权（+0.0402）战胜所有拟合模型**

这是 p/n 纪律最强的实证：

```
n = 64 个独立期，Ridge 要估 3 个系数 → p/n = 0.047
但门槛要求 p/n < 1/50 = 0.02
→ 连 Ridge 都超标 2.3 倍
→ 等权（p=0）反而最稳
```

**注意**：等权用的方向来自全训练窗，5 折时存在轻微乐观偏差（已在正文披露）。

## E″｜PCA 风险分解（F6 的合法用途）

**手册规则**：PCA 先当**风险分解与中性化工具**，不要当 alpha 发生器。

### 全市场组（3 因子）

| 主成分 | 方差解释率 |
|---|---|
| PC1 | 39.4% |
| PC2 | 32.7% |
| PC3 | 27.9% |

**载荷（PC1 / PC2）**：

```
PC1: [-0.6956, -0.0544, -0.7164]
PC2: [0.5567, -0.671, -0.4897]
```

**关键发现：三个主成分的方差几乎是均分的（39.4% / 32.7% / 27.9%）。**

这有两层含义：

```
① 说明三个因子确实提供了三个几乎正交的方向
   → 与 F6 的相关性分析一致（最大 |ρ| = 0.173）
   → 没有哪个主成分是"市场 beta 主导"

② 反面：如果 PC1 解释 80%+，说明所有因子在测同一件事
   → 那时才需要用 PCA 降维
   → 我们不需要
```

**制造业组（2 因子）**：

| 主成分 | 方差解释率 |
|---|---|

| PC1 | 61.8% |
| PC2 | 38.2% |

两个成分 61.8% / 38.2%，比全市场组更不均等，但仍在同一量级。

**BBP 阈值的说明（诚实标注）**：

```
BBP 阈值 ≈ 1 + √γ，γ = p/n
我们算得 γ = 0.000010，阈值 1.0032

但这个阈值是对「标准化后的特征值」定义的，我直接用未标准化的协方差特征值比较，
实现的严谨性不足 → 不把 n_effective_components 作为结论依据。
可用的结论是方差解释率的分布（上面那张表）本身。
```

**本项目为什么不用 PCA 降维**：

```
① p 只有 2~3，降维收益极小
② 三个主成分方差均分 → 没有冗余方向可压
③ 把手册明确：PC 不当 alpha 发生器
④ 若要中性化（剥掉 PC1），属于「表示=去残差」，是改含义 → 需重跑 F7
```

## E｜族内选谁

**线性族内决策**：
| 候选 | 决定 | 理由 |
|---|---|---|
| **等权 / IC 加权合成** | ✅ **采用** | 零参数、无过拟合风险、可解释、换手最低 |
| Ridge | ⚠️ 备选 | 参数只有 3~2 个，但需选 α（多一个旋钮） |
| LASSO | ❌ 否掉 | 特征少（3 个）且相关低，稀疏化无意义 |
| 分位数回归 | ❌ 否掉 | 只要均值排序 |

**实测的反直觉结果（必须诚实报）**：

| 组 | 等权 | Ridge | GBDT | 谁最好 |
|---|---|---|---|---|
| 全市场组 | +0.0402 | +0.0193 | +0.0201 | **等权** |
| 制造业组 | +0.0215 | +0.0556 | +0.0377 | Ridge |

**全市场组：等权（+0.0402）远胜 Ridge（+0.0193）**，说明在 64 个独立期、每折约 13 期的条件下，
拟合系数的不稳定性超过了它带来的收益。这正是手册「样本少就走最简」的实证。

**制造业组：Ridge（+0.0556）胜等权（+0.0215）**，因为只有 2 个特征、共线性低，估 2 个系数相对稳。
**但必须披露一个偏差**：等权用的方向（+1/+1）来自全训练窗 F7 的结果，
而 5 折的每折训练集排除了该折 → 等权实际上用了该折的信息，存在轻微乐观偏差。
所以「等权胜 Ridge」这个结论要打折看；但「GBDT 未胜 Ridge」这个结论不受此影响。

## F｜什么时候停止升级

停止条件（按顺序触发）：
1. 非线性相对线性的 IC 提升 < 0.003 → **停在等权/线性**（本次已触发）
2. 折级 IC 的置信区间重叠 → 停在简单模型
3. 增加特征后增量 IC < 0.003 → 停止加特征（F7 已执行）
4. 过拟合度 > 0.6 → 退回更简单模型（M-V 检查）

**本次结论：停在「等权 / IC 加权合成」，不进非线性。**

## 否掉的候选清单

| 候选 | 否掉理由 |
|---|---|
| 分类（逻辑回归/GBM 分类） | 只要排序，概率水平不进入决策；且需额外选阈值 |
| 排序学习（lambdarank） | 截面已天然按分数排名，回归够用；lambdarank 需构建组内配对，复杂度无收益 |
| **GBDT（HistGradientBoosting）** | **实测相对 Ridge 提升 < 0.003，未过硬门槛** |
| 随机森林 | 同 GBDT，且换手更高 |
| LASSO / ElasticNet | 特征仅 2~3 个且相关低，稀疏化无意义 |
| 分位数回归 | 只要均值排序，不需区间 |
| Kalman / GARCH / HMM | F4 已判定不适用 |

## 复杂度成本账（G-S.7）

| 项 | 等权/线性 | GBDT | 差异 |
|---|---|---|---|
| 训练成本 | 秒级 | 秒级（小数据） | 近似 |
| 推理成本 | O(p) 点积 | O(树数×深度) | GBDT 略高 |
| **调参成本** | **0 个超参** | **≥5 个**（深度/学习率/迭代数/叶样本数/L2） | **GBDT 需更多试验 → N 更大 → Bonferroni 门槛更高** |
| 维护成本 | 低（无模型文件） | 中（需保存模型 + 版本） | GBDT 高 |
| **换手成本** | **低（平滑）** | **高（阶跃）**，手册实测高 28~55% | 直接吃掉 alpha |

**结论：GBDT 多付出的调参试验次数会抬高 E7 的 Bonferroni 门槛，
而其 IC 提升未过 0.003 门槛 —— 复杂度不划算。**

## 最终决定

| 组 | 模型 | 特征 | 理由 |
|---|---|---|---|
| 全市场 | **IC 加权合成**（零参数） | gm_vol, dgm_q, gm | 等权实测 +0.0402 > Ridge +0.0193 > GBDT +0.0201 |
| 制造业 | **IC 加权合成**（零参数），Ridge 作备选 | transfer_intensity, dep_rate | Ridge 实测 +0.0556 > 等权 +0.0215；但仅 15 期，优先零参数，M-V 再定 |

**为什么即使制造业 Ridge 更好，仍以零参数为主**：
① 仅 15 个独立期，估 2 个系数的标准误极大
② 零参数不需要 CV 选 α → 少一次试验 → E7 的 Bonferroni 门槛更低
③ Ridge 作为备选保留，M-V 用 Purged CV 再判

**这是最终选择。M-C 将检查校准需求，M-V 将用 Purged CV 检验稳定性。**

## 已知局限

1. 交叉验证用简单时间分折（50/5≈13 期/折），未做 purge+embargo（期数太少，purge 后无训练样本）
2. 制造业组只有 15 期，5 折后每折仅 3 期，IC 估计极不稳定
3. 未做 HAC 标准误检验「折级 IC 置信区间是否重叠」——因每折期数太少，CI 本身不可靠
4. 等权 vs Ridge 的对比未做（留下次）

## ⚠️ 口径注记（metric_spec.md v1.0 后加）

本文档里的合成 IC 数字（等权 +0.0402 / Ridge +0.0193 / GBDT +0.0184）是用**折内 rank** 算的

**正确口径（期内 rank）的结果是：等权 +0.0496 / Ridge +0.0300 / GBDT +0.0264。**

| 项 | 本文档（折内 rank） | 正确（期内 rank） |
|---|---|---|
| 等权 | +0.0402 | **+0.0496** |
| Ridge | +0.0193 | +0.0300 |
| GBDT | +0.0184 | +0.0264 |

**核心结论不受影响**：三种口径下「等权 > Ridge > GBDT」的相对排序完全一致，
所以「非线性不采用」与「等权优于拟合权重」这两个判断仍然成立。

**但绝对数值应以 `metric_spec.md` 登记的 +0.0496 为准。**
详见 `metric_spec.md` 第三、四节。
