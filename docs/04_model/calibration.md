## 一、是否需要校准（G-C.2）

**结论：不需要概率校准；但做了区间校准作为方法论演示。**

**手册判定规则**：

> 先问「下游用不用水平」。不用水平 → 跳过概率校准；用水平 → 必须校准。

**三层判断**：

| 层 | 问题 | 我们的答案 |
|---|---|---|
| ① | 下游用不用概率水平？ | **不用**。下游是选 top-k 后等权/IC 加权持有，权重不依赖分数大小 |
| ② | 需不需要区间？ | **不需要**。不做仓位择时、不做风险预算，只做选股 |
| ③ | 有没有误用风险？ | 唯一风险是把排序分数当预期收益用。手册明令禁止，本项目的分数**只用于排序** |

**为什么排序分数不需要概率校准（数学原因）**：

```
IC（Spearman）是秩相关 → 对任何单调变换不变
f(x) → rank(f(x)) 与 rank(x) 完全相同 → IC / 换手 / 选股全部不变
→ 做 Platt 或 isotonic 校准不会改变任何下游结果
```

**手册对排序族的原话**：

> 序已够用 → **免校准**（排序对失校准稳健，这是默认选择）。
> **禁止**把 LTR 分数直接当预期收益用。

## 二、边际覆盖率（G-C.3 / G-C.4）

**方法**：split conformal（残差离散度均匀时最易审计的方案）。
目标覆盖 1−α = 90%，接受区间 88~92%。

### 全市场组

| 折 | 测试样本数 | 覆盖率 | 区间宽度 | conformal 分位 q |
|---|---|---|---|---|
| 2 | 33,520 | 89.6% | 0.8949 | 0.4474 |
| 3 | 43,662 | 90.5% | 0.8973 | 0.4487 |
| 4 | 53,198 | 89.3% | 0.8928 | 0.4464 |
| 5 | 27,483 | 90.2% | 0.9003 | 0.4501 |

**边际覆盖率 = 89.9%** ✅ 落在 88~92%

### 制造业组

| 折 | 测试样本数 | 覆盖率 | 区间宽度 | conformal 分位 q |
|---|---|---|---|---|
| 2 | 5,950 | 89.5% | 0.8931 | 0.4466 |
| 3 | 10,362 | 89.8% | 0.8935 | 0.4467 |
| 4 | 13,529 | 90.0% | 0.8963 | 0.4482 |
| 5 | 4,100 | 89.2% | 0.8965 | 0.4482 |

**边际覆盖率 = 89.6%** ✅ 落在 88~92%

### ⚠️ 一个必须指出的负面发现：区间几乎没有信息量

区间宽度约为 **0.89**，而目标变量是期内 rank（取值 0~1，全距 = 1.00）。
也就是说：区间覆盖了 **89% 的整个取值范围**，只比「无条件给全区间」窄 11%。

**这说明什么**：
```
覆盖率 89.9% 达标，但那是靠「给一个几乎无用的宽区间」换来的
→ 模型的水平预测能力极弱（IC≈0.04 对应 R²≈0.0016）
→ 这恰恰印证了「只能用排序，不能用水平」
→ 若把区间用于风险预算，会得到几乎无差异的仓位
```

**这是一个有价值的负面结论**，不是失败——它用定量方式证明了「这套因子只能做排序」。

## 四、校准集与训练集不相交（G-C.6）

**实现**：每折内部按时间三段切分——

```
训练集：测试折之前的前 75% 期间
校准集：测试折之前的后 25% 期间（与训练集严格不相交）
测试集：该折本身
```

**为什么必须不相交**：用训练集做校准会让残差被低估 → 区间过窄 → 覆盖率虚高（看似 98%），实际样本外崩。

## 五、Brier / ECE（G-C.7）

**背景**：本项目概率水平不进入决策，本可不做。但为了如实回答「是否可用概率」，
仍做了二分类版本（未来 60 日收益 > 0）的完整校准，并报 Brier 与 ECE。

**方法**：逻辑回归（输入为等权因子分数）→ 校准集上做 Platt / isotonic → 测试集上评估。
校准集与训练集严格不相交（同 G-C.6 的三段切分）。

### 三个必须承认的负面结论

**① 概率输出几乎无信息量**

```
全市场组的 raw Brier 0.2757，而「永远猜基线率」的 Brier 只有 ~0.25
→ 模型给出的极端概率（接近 0 或 1）是错的
→ 用它在水平上决策会亏得比瞎猜更多
```

**② 校准本身不稳定**

```
全市场组折2：Brier 0.3592 → Platt 0.2532（大幅改善）
制造业组折5：Brier 0.2095 → Platt 0.2965（反而变差）
→ 校准集太小（每折仅约 64 期的 25%）→ Platt 参数估计不稳
```

**③ ECE 普遍很高（0.13~0.19）**

```
ECE 0.15 意味着：预测概率 0.7 时，实际命中率可能只有 0.55
→ 可靠性分箱图不会单调
```

### 这恰好印证了 M-S 的决策

```
排序（IC）能用：+0.04 ~ +0.06，虽然弱但方向一致
水平（概率）不能用：比常数基线还差
→ 同一个因子，在排序任务上有效、在水平任务上无效
→ 这正是「任务形态决定模型族」的直接证据
```

**所以本项目不使用概率做任何决策，只使用排序。**

## 六、结论

| 项 | 结论 |
|---|---|
| 需要概率校准吗 | **不需要**（下游只用排序） |
| 需要区间校准吗 | 不需要；但已做 split conformal 作演示 |
| 边际覆盖率 | 全市场 89.9% / 制造业 89.6%（均达标） |
| **区间信息量** | **几乎为零（宽度≈全距）→ 只能排序** |
| 分层覆盖 | 各折稳定（89.2~90.5%）；regime 分层 89.0~90.4%，无塌陷 |
| **Brier / ECE** | **raw 0.2757 / 0.2648（全市场/制造业），劣于常数基线 ~0.25；ECE 0.13~0.19 → 概率不可用** |
| 校准集独立性 | 严格不相交（时间三段切） |

**一句话**：校准做对了（覆盖率达标），但校准的有效性暴露了因子的水平预测能力极弱——
这不是校准的问题，是因子本身只含排序信息。**这进一步支持 M-S 的「零参数排序」决策。**
