## 二、标签公式

```
entry = open_adj[t+1]        # T+1 开盘买入
exit  = open_adj[t+60+1]      # 持有 60 日后开盘卖出
label = exit / entry - 1
```

**为什么是 T+1 开盘**：T 日 15:00 才知道收盘价，15:00 后无法交易；
T+1 开盘是第一个可执行时点。此惯例放弃了 T 日收盘到 T+1 开盘的隔夜收益——这是必要代价。

## 三、复权开盘价

```
adj_factor = close_adj / close
open_adj   = open × adj_factor
```

## 六、与回测的一致性

- 回测入场价必须是 `open_adj[t+1]`
- 回测出场价必须是 `open_adj[t+H+1]`
- 剔除样本必须与本文档一致


## 七、与可交易性的一致性

- 收益用复权序列（`open_adj` / `close_adj`）
- 可交易性用原始序列（`close` / `limit_up`）
- 不可交易样本（`tradable=False`）不计算标签


## 八、已知局限

1. **放弃隔夜收益**：T 日收盘到 T+1 开盘的跳空不计入
2. **开盘冲击未建模**：假设按开盘价足额成交，未考虑集合竞价冲击
3. **年成本偏高**：4.16 倍年换手 × 20bp = 8.3%，对小超额策略是硬约束
4. **H=60 导致重叠**：相邻样本标签重叠 59 天，独立时间点仅 66 个
