## 二、universe 四要素

| 要素 | 阈值 | 实现 | 理由 |
|---|---|---|---|
| 上市天数 | ≥ 250 交易日 | `groupby(code).cumcount()+1` | 保证能算 250 日动量等年度级因子 |
| 非 ST | `st_flag == 0` | `trade_status ∈ {2,3,6}` 取反 | ST 涨跌幅 5%，制度扭曲信号 |
| 成交额分位 | > 20% | 20 日均值后按日截面 `rank(pct=True)` | 保证容量与冲击成本可控 |
| 有成交 | `volume > 0 且 close 非空` | CSMAR 停牌日整行缺失 | 停牌无法成交 |

## 三、可交易性 mask

| 条件 | 处理 | 理由 |
|---|---|---|
| 停牌 | 剔除 | 无法成交（含在 universe_ok 的 has_quote） |
| 涨停 | **剔除** | 买不进（`hit_limit_up=True`） |
| 跌停 | 保留 | 多头买入不受阻；调仓卖出需在回测中单独记录 |

## 四、一致性保证

特征、标签、回测三处共用同一判定函数：

```python
tradable = universe_ok & ~hit_limit_up
# tradable ⊆ universe_ok 已用 assert 校验
```

实测：`(tradable & ~universe_ok).sum() == 0` ✅

## 六、已知局限

1. **上市天数用 cumcount**：数据自 2010-01-04 起，2010 年前上市的股票其 listed_days 从 1 开始，导致 2010-2011 年 universe 偏小。这是数据起点截断，需在报告声明。
2. **成交额分位按当日截面**：极端行情日（如 2015 股灾）分位不稳定。
3. **北交所未单独处理**：涨跌幅 30%、流动性显著低于主板，未做差异化规则。
4. **退市股处理**：delist_date 由行情末行推导（当时可观察），未使用今日退市名单，避免幸存者偏差。
